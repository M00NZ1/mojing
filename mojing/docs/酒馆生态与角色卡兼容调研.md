# 角色卡与聊天记录兼容

墨境支持角色卡、WorldInfo 和聊天记录导入，以及本应用的便携角色包。导入数据转换为墨境的角色、百科和消息结构。

## 格式入口

| 格式 | 用途 |
|---|---|
| PNG 角色卡 | 从图片文本块读取角色资料 |
| JSON 角色卡 | 读取角色卡对象与 V2 `data` 内容 |
| JSON/TXT/DOCX 便携包 | 转移墨境角色配置与详细资料 |
| WorldInfo JSON | 转换为百科条目 |
| 聊天 JSON/JSONL | 导入会话正文 |

Web 角色库提供统一导入窗口，完成后可直接打开角色。PNG 链接入口读取远程图片中的角色资料。

## PNG 与 JSON 角色卡

Web PNG 解析器识别 `chara` 文本块，支持 `tEXt` 中的 Base64 JSON，以及 `zTXt` 中压缩的 JSON。JSON 角色卡支持顶层角色对象和 V2 `data` 对象。

### Web 字段映射

| 角色卡字段 | 墨境处理 |
|---|---|
| `name` | 角色名称 |
| `description`、`personality` | 组合为角色设定 |
| `scenario` | 加入场景段落 |
| `first_mes` | 开场白与角色设定段落 |
| `mes_example` | 对话示例段落 |
| `system_prompt` | 系统提示与角色设定段落 |
| `post_history_instructions` | 后置指令段落 |
| `creator_notes` | 创作者备注段落 |
| `alternate_greetings` | 备选开场白 |
| `character_book` | 角色世界书 |
| `tags`、`creator` | 标签与创作者信息 |

角色卡中的提示文本按墨境上下文规则组装。第三方脚本、插件及扩展运行逻辑不随文件导入执行。

Web PNG 上传与链接读取上限为 32 MiB，链接连接和读取超时为 30 秒。

Web PNG 导出使用 V2 容器，`description` 保存完整角色设定，其他拆分文本字段使用默认值。头像转换为 PNG 并按图片方向信息调整，角色数据写入图片结束块之前。墨境的模型参数与 `profile` 详细资料通过便携包转移。

在角色的“资料工具”中点击“导出 PNG 角色卡”。修改保存后可导出，下载期间显示处理状态，失败后可重试。

## 便携角色包

Web 便携格式支持 JSON、TXT 和 DOCX，包含版本、角色名称、设定、模型参数和 `profile` 详细资料。导入时角色与详细资料在同一事务保存；同名角色分配新名称。

TXT 与 DOCX 使用本应用的便携结构。DOCX 读取保留段落、换行和转义正文。导出不包含 API Key。

| Web 接口 | 功能 |
|---|---|
| `POST /api/characters/import-card` | PNG 导入 |
| `POST /api/characters/import-card-json` | JSON 角色卡导入 |
| `POST /api/characters/import-url` | 链接导入 |
| `POST /api/characters/import-portable` | 便携包导入 |
| `GET /api/characters/{id}/export-card` | PNG 角色卡导出 |
| `GET /api/characters/{id}/export-portable` | 便携包导出 |

## 聊天记录

Web 酒馆聊天导入支持根级 `mes[]` 和 JSONL。正文从 `mes`、`message` 或对应 JSONL 的 `content` 读取，发言类型由 `is_user` 或 `role` 判断。

`POST /api/sessions/{session_id}/import-tavern-chat` 接收文件、`character_id` 和 `branch_id`。角色必须属于目标会话，非用户消息归入所选角色；`branch_id` 指定目标故事线，缺省为 `main`。

Android 的 `TavernChatImportParser` 支持 `mes[]`、本应用 `messages[]` 和 JSONL，并按发言顺序与正文生成稳定批次标识。

聊天文件导入提取消息正文与发言类型；原工具的插件状态和交互脚本不作为会话运行状态导入。

## WorldInfo

WorldInfo 条目转换为百科标题、正文、关键词及扩展元数据。详细容器与字段映射见[世界百科与资料导入](世界百科资料库模板与来源导入.md)。
