## 文档维护规则

1. 产品定位、功能状态、非目标和优先级只更新 [`../PROJECT.md`](../PROJECT.md)。
2. `ANDROID.md` 只维护 Android 架构与可执行验收，不复制完整功能清单。
3. `MAINTENANCE.md` 只记录命令、验证证据、数据保护、发布和清理。
4. 专题研究必须注明与代码的核对边界；过时施工文档归档或删除。
5. 新增文档前先确认现有入口不能容纳该内容，避免同一需求出现多个真源。
6. 文档、日志、导出包和截图中禁止写入 API Key、Token、签名密码或其他凭证。
7. 合并前运行 Markdown 本地链接和重复标题/重复文档检查。
