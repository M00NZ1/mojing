# 世界百科与资料导入

世界百科集中管理设定条目、人物关系和时间线，并可绑定到会话。世界模板保存开局与运行设定，Lore 提供会话中的世界资料。

## 百科结构

| 对象 | 内容 |
|---|---|
| 百科库 | 名称、说明及所属条目 |
| 条目 | 类型、标题、摘要、正文、标签、封面和扩展字段 |
| 关系 | 起点条目、终点条目、关系类型与说明 |
| 时间线 | 事件、时间与关联资料 |
| 版本 | 条目正文和元数据快照 |

条目类型包括人物、地点、势力、事件、物品、技能、职业、概念、种族、世界观、时间线和其他。

内置资料为“雾港来信”，目录见[内置资料说明](../data/builtin_pack/README.md)。

## 创建与整理

在创作中心进入百科，创建百科库后添加条目、关系和时间线。条目编辑支持摘要、正文、标签和扩展资料；版本接口提供历史快照。

世界创作支持生成世界与整理已有文本。生成记录保存进度和结果，支持暂停、继续和保存到世界库。

## WorldInfo 导入

Web 接口：

```http
POST /api/encyclopedia/{encyclopedia_id}/import-worldinfo
Content-Type: application/json
```

请求字段 `json_text` 是 WorldInfo JSON 文本。支持的容器包括：

- 顶层条目数组。
- `entries`、`lorebook` 或 `data` 数组。
- `entries` 对象，值为条目。

例如：

```json
{
  "json_text": "{\"entries\":[{\"comment\":\"雾港灯塔\",\"keys\":[\"灯塔\"],\"content\":\"旧灯塔位于港口北岸。\"}]}"
}
```

导入后创建 `concept` 类型条目，返回 `created` 数量。

| WorldInfo 字段 | 百科字段 |
|---|---|
| `comment` / `name` | 标题；缺省时使用关键词或序号 |
| `content` | 正文；摘要取前 400 字 |
| `keys` / `key` | 标签及 `wi_keys` |
| `secondary_keys` | `meta_json.wi_secondary_keys` |
| `constant`、`selective` | 对应 `wi_*` 元数据 |
| `depth`、`order`、`uid`、`position` | 对应 `wi_*` 元数据 |
| `extensions` | `meta_json.wi_extensions` |

导入字段按墨境的百科与上下文规则使用，扩展字段保存在元数据中。

解析实现：[worldinfo_import_service.py](../backend/app/services/worldinfo_import_service.py)、[worldinfo_import.py](../backend/app/services/worldinfo_import.py)。Android 对应 [WorldInfoImportParser.kt](../android/app/src/main/java/com/mojing/app/domain/encyclopedia/WorldInfoImportParser.kt)。

## 本机 API

以下路径使用默认前缀 `/api/encyclopedia`。

| 方法与路径 | 功能 |
|---|---|
| `GET /types`、`GET /entry-types` | 条目类型 |
| `GET /relation-types` | 关系类型 |
| `GET /schemas` | 条目扩展结构 |
| `GET /template-modules` | 模板模块定义 |
| `GET /source-policy` | 来源分类与内容规则 |
| `GET /entries` | 查询条目 |
| `GET /entries/{entry_id}/versions` | 条目版本 |
| `GET /{encyclopedia_id}/relation-graph` | 百科关系图 |
| `GET /timeline` | 时间线 |
| `POST /{encyclopedia_id}/import-worldinfo` | 导入 WorldInfo |

`bootstrap-template` 是逐条写入示例模板的兼容接口。`import-sources` 当前为兼容响应，返回空导入统计；资料导入使用 WorldInfo、条目编辑或文本整理入口。

路由实现见 [encyclopedia.py](../backend/app/routes/encyclopedia.py)。

## 世界模板包

Web 世界模板与 Lore 通过本机 API 导出为 v1 世界包。导入先解析完整内容、检查版本和标识冲突，再统一写入。

“替换全部自定义模板”保留同标识模板的数据库 ID，并移除包外的自定义模板。内置模板不参与覆盖。生成记录中的原始结果与世界库中的可编辑模板分别保存。

更多实现见[产品与架构](../PROJECT.md)。
