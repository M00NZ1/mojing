# 墨境产品与架构

墨境是本地优先的 AI 角色扮演、长篇对话和世界设定工作台，包含 Web 客户端与原生 Android 应用。

## 产品结构

Android 界面采用墨色底与青绿强调色，保留八套可选主题。输入框、按钮、面板和文字层级使用统一组件规范，底部导航为悬浮圆角布局，页面前进与返回采用轻位移动画。图标以书页与入口为意象；启动页标语为“以墨为界，入境如梦。”，配合柔光背景与分阶段入场。

首页空列表提供页面内开始入口；已有对话时显示悬浮新增按钮，列表底部预留操作空间。

| 模块 | 功能 |
|---|---|
| 对话 | 单角色与多角色会话、流式回复、停止、重试、继续生成 |
| 剧情 | 消息编辑、回复版本、故事线、检查点、动态选项 |
| 角色 | 角色卡、详细资料、用户人格、独立模型线路 |
| 世界 | 百科、条目关系、时间线、WorldInfo、世界模板 |
| 创作 | 世界生成、文本整理、故事推演、生成记录 |
| 历史与记忆 | 分页、搜索、收藏、摘要、长期事实与来源 |
| 媒体 | 图片生成、语音合成、语音输入、附件 |
| 数据交换 | 角色卡、聊天记录、世界包与本地备份 |

Web 主导航为对话、创作和设置。创作中心连接角色、百科、设定工坊与故事推演。

角色定义参与者，百科保存世界知识，设定工坊配置开局玩法与叙事规则。Android 角色可独立开聊，无需先绑定百科；未绑定角色也可加入选定百科的会话。百科列表支持重命名。

Android 百科条目保存有对话来源时，编辑页提供“查看对话原文”。原文支持滚动与复制，可进入来源故事线并定位对应消息，返回后继续编辑百科草稿。读取失败可重试，来源删除后保留百科内容；来源故事线已删除时提示返回百科。

来源对话在原文定位完成后显示历史窗口；加载失败或消息缺失时提供重试和返回百科入口。

自动沉淀条目的原文预览展示来源计数，支持逐条浏览整理依据；每次读取一条消息，进入故事线时定位当前来源。部分来源删除不影响浏览其余记录，旧条目继续使用单条来源。

百科列表与编辑页统一展示确认状态，自动沉淀标为“对话推断”。沉淀资料支持全部、待核对、已确认筛选及数量显示；待核对包含所有尚未确认的条目。编辑页在正文前提供状态选择，核对来源后可设为“已确认”并保存，来源记录继续保留。返回百科时保留主标签与条目分类，并刷新保存后的内容。

Web 与 Android 沉淀资料支持列表内批量核对，可逐条选择或选择当前筛选下前 100 条待核对资料，一次确认最多 100 条。确认更新状态与时间，保留正文和来源；失败保留选择，切换筛选清空选择。Web 同时保存条目版本，状态与版本在同一事务中提交；列表使用紧凑分段筛选，长摘要显示三行，点击标题进入详情。

Web 沉淀资料按创建顺序由新到旧浏览，每页最多 100 条，支持上一页、下一页与读取失败重试。确认状态在查询时筛选；翻页清空选择并回到列表顶部。查询采用稳定 ID 游标，列表只读取标题、状态、来源与最多 480 字的摘要，正文通过详情加载。

从 Web 沉淀资料打开条目后，可通过“返回沉淀资料”恢复当前筛选、页码和条目位置。详情读取失败时保留同一返回入口；返回列表重新读取本页，切换百科清除浏览位置。

百科条目与关联资料按最新刷新请求更新。快速切换分类或重新打开百科时，旧查询结果自动失效；时间线、关系和沉淀资料的连续读取使用同一个百科 ID。

Android 角色人设与百科正文使用可展开的长文本输入框：默认最多显示六行，展开后最多十六行，其余内容在框内滚动。展开与收起保留当前编辑内容，保存沿用页面现有入口。

Web 角色人设与百科正文同样支持展开、收起及框内滚动。编辑区高度随屏幕限制，展开按钮支持键盘操作，保留原有字数限制与表单保存入口。

Web 角色 AI 补全支持停止和重试；切换角色或离开补全区域时取消本页请求。补全只合并人设字段，保留等待期间修改的其他资料；人设已被手动修改时保留当前草稿并显示提示。

Web 角色保存使用提交快照，保存期间新增的编辑继续留在草稿中，并保留未保存提示。重新进入角色编辑页后，旧页面的保存响应不覆盖当前草稿。

Web 角色头像上传提供处理中状态和失败重试提示。头像上传与立绘生成结果绑定发起时的角色及编辑页，保留处理中手动选择的图片和其他草稿内容。

Web 桌面对话消息菜单支持方向键循环选择、Home/End 首尾定位、Esc 返回操作入口和 Tab 离开菜单。移动端操作面板展示发送者与两行消息预览，关闭入口固定在顶部，操作区独立滚动。输入法选词期间保留菜单状态。

Android 消息操作面板同样保留顶部关闭入口、发送者和两行原文预览，操作列表独立滚动；生成期间继续按操作类型控制可用状态。操作面板与撤回确认统一使用可见正文预览，用户输入的结构标签按原文保留。

Android 消息编辑采用自适应底部面板，正文独立滚动，标题、关闭与保存入口固定显示。键盘弹出时收起操作说明，为正文保留空间；关闭或下滑退出已修改的草稿时提供放弃确认。保存继续创建编辑故事线。

消息编辑保存中显示提交状态并锁定编辑与退出；写入失败在面板内提示，保留草稿供重试。分支已写入而后续加载失败时显示“已保存”，保留错误说明并禁用重复提交。

角色采样参数以文本草稿编辑，支持清空重填、小数和负数。输入框显示格式错误，保存及导出前统一校验数值；最大 Token 使用正整数，其他参数使用有限数值。键盘“完成”结束输入并收起键盘。

Android 消息引用以独立区域展示；气泡配色随主题切换。记忆面板展示当前长期记忆，提供重建、清空和长文本展开；小说旁白完成后整理事件，并按世界设置沉淀百科条目。

Android 聊天未指定会话模型时显示“跟随角色与模型设置”；指定后显示平台与模型名。模型列表按平台 ID 和模型名标记当前选择，支持同名平台区分；搜索时优先展示匹配结果，清空搜索后恢复线路说明。

模型面板可恢复“跟随角色与模型设置”，从下次发送沿用角色独立配置及公共设置。恢复只清除当前会话的模型选择，保留平台、Key 与其他会话配置，支持保存状态和失败重试。

Web 模型面板采用固定标题、搜索、默认配置和管理入口，模型列表独立滚动并按可见范围渲染。选中项使用主题高亮与勾选标记；保存时显示进度并保留弹窗，支持失败重试与中文输入法选词。未指定会话模型时同样显示“跟随角色与模型设置”。

Web 模型列表支持方向键逐项浏览、Home/End 定位首尾可用模型和 Enter 选择；跳过未配置 Key 的平台。键盘导航自动滚动至目标，虚拟列表保留当前焦点项。

Web 平台编辑的默认模型使用可搜索选择面板，每页显示十项，支持翻页、选中高亮、无结果提示及键盘关闭。模型名称较长时保留完整选项文本，收起后显示省略预览。

用户纠正保存后刷新当前故事线的记录，按分支与请求顺序处理查询结果，保持最新内容。

生成记录的取消确认展示实时保存进度与操作状态，失败可在确认框内重试，取消后保留已保存内容。

生成记录详情支持查看已生成内容，读取失败时保留详情并提供重试；关闭面板或离开页面会取消结果查询。

Android 生成反馈与打开失败提示默认显示三行，长文本提供展开与收起。展开后的反馈在有限高度内滚动并支持选择复制，短提示直接显示；内容更新后恢复预览状态。

生成详情的打开失败反馈位于可滚动内容区，新错误出现时回到内容开头。重试与关闭固定在底部，长标题及展开反馈不挤占操作区。

Android 生成记录详情按任务 ID 恢复选择，界面重建后随任务列表重新显示。打开的详情跟随最新进度和状态；列表暂时变化时保留最近内容，关闭后清除详情选择。

Android 生成记录的分类筛选在滚动时保持吸顶，切换“全部、进行中、需处理”后从列表开头浏览。界面重建保留原分类与滚动位置。

生成记录提供近期与全部两种浏览模式。近期优先显示进行中的任务；全部记录按 ID 从新到旧分页，每页最多 50 项，支持前后翻页和查询前分类筛选。旧记录可继续查看详情、打开生成内容及重试，翻页失败可重新读取或切换分类。

浏览模式、分类和分页游标统一保存在 Android 页面恢复状态中，界面与查询共享同一份选择。切换分类同时重置游标，返回近期记录同时恢复“全部”分类。

Web 通用按钮随主题提供默认、悬停、按下、禁用与键盘焦点状态；主按钮采用清晰的实色表面与轻量阴影。

Web 确认弹窗的长说明可独立滚动，保留底部输入与操作入口，支持键盘阅读和中文输入法选词。

连续触发确认时保留最新请求，被替换的操作按取消处理；请求中止仅影响对应弹窗。

Android 小说开局页分别展示来自工坊的玩法和来自百科的世界知识，选定后可预览、展开组合设定。章节数量使用明确的选中状态。

Android 对话将百科基础背景与检索条目共同提供给角色和旁白，已有开局快照包含的背景不重复注入。会话资料的世界页支持查看、展开本场基础设定。

Android 生成记录在重新排队期间显示任务级进度并禁用重复提交；操作提示保持到正常消失，旧提示不会清除后续操作的反馈。

生成记录区分加载、空记录和读取失败；读取中断保留已显示记录，可原地重新读取，不触发任务重新生成。查看生成内容前按任务类型校验目标；目标已删除或读取失败时保留记录并显示提示，打开期间防止重复跳转。

Android 记忆面板优先展示用户纠正，提示依据默认折叠；长期记忆、摘要和关键事实按实际长度展开。纠正与摘要使用独立列表标识，避免同号记录冲突。

初始资料“雾港来信”包含一个百科、一个世界、沈照与林汐两名角色。目录定义与安装规则见[内置资料说明](data/builtin_pack/README.md)。

## 工程结构

以下路径相对于 `mojing/`：

```text
backend/app/routes/                       HTTP 接口
backend/app/services/                     会话、创作、检索与导入业务
backend/app/models.py                     SQLAlchemy 数据模型
backend/storage/                         SQLite 与本地文件
frontend/src/                            React 页面、组件与状态
android/app/src/main/java/com/mojing/app/ 原生应用源码
android/app/src/test/                     JVM 测试
android/app/src/androidTest/              Android 测试
data/builtin_pack/                       初始资料与资源
scripts/                                 开发与维护脚本
```

Web 使用 React、TypeScript 和 Vite，本机 API 使用 FastAPI、SQLAlchemy 和 SQLite。Android 使用 Kotlin、Jetpack Compose、Room、ViewModel 与 Repository。

| 数据 | Web | Android |
|---|---|---|
| 会话、消息、分支 | SQLite | Room |
| 角色、百科、世界模板 | SQLite 与文件 | Room 与应用文件 |
| 平台、Key 与偏好 | 本机配置与数据库 | SecureStorage 与偏好存储 |
| 图片、音频、附件 | Backend 文件存储 | 应用文件与授权 URI |
| 交换数据 | 本地导入导出 | 本地导入导出 |

## 模型与请求

Android 模型选择面板区分下次发送线路和最近请求模型。生成期间切换模型，从下一次发送生效；最近请求模型在当前页面中保留，便于对照。底部面板固定搜索与关闭入口，长模型信息和按平台分组的模型列表可滚动浏览。

返回对话时刷新模型名称。设置中的默认线路适用于未单独选择模型的会话；会话中已选择的模型保持独立。

记忆、事件、书签和搜索支持定位历史原文。历史加载期间保留查找入口，加载完成后可继续定位。

模型选择保存期间显示进度，成功后更新名称并关闭面板；失败保留选择面板并显示重试提示。

平台预设为 DeepSeek、OpenAI、硅基流动、Anthropic 和自定义。每个平台独立保存名称、地址、Key 与模型清单，支持多个同类平台配置。

模型发现使用对应平台的认证与列表接口，Anthropic 模型列表支持分页；模型名称也可以手动填写。Web 对话使用现有 Chat Completions 兼容客户端。

默认平台提供公共文字线路，角色可配置独立线路。聊天页手动选择模型后，会话选择优先，从下一次发送生效；同一轮角色与旁白使用固定线路快照。

切换服务商或修改接口地址时处理相应凭据，不复用其他平台的 Key。平台编辑与其他设置分别保存。

## 会话、消息与分支

Web 消息编辑失败时在弹窗内显示错误并保留草稿，可直接再次提交；编辑故事线保存后可从故事线入口打开。

对话输入区显示两行引用预览，可直接取消；再次引用回复时使用该回复自身的正文。

Android 消息复制、编辑与引用保留用户输入的字面标签；模型结构化回复按可读正文处理。

会话绑定角色、世界设定和人格。当前故事线控制可见消息、上下文、搜索范围与回复落点。编辑、回复版本和分支保留原始剧情。

Web 删除消息前读取关联信息，提交时再次检查故事线、检查点和编辑来源。Android 撤回在 Room 事务中检查引用，并处理回复版本回退和带归属标记的同线生成媒体。操作完成后加载附近历史窗口。

Web 消息菜单提供上下文排除与恢复。该设置保留原文、搜索和导出，从下一轮请求生效。

## 历史与搜索

会话通过稳定消息 ID 分页读取，搜索定位使用目标附近的消息窗口。

Web 当前故事线搜索使用 SQLite FTS5 单字、双字索引与原文子串复核。结果按消息 ID 倒序分页；首次索引从近期历史分批推进，新增、编辑和删除通过事务记录变更，再增量更新索引。

索引整理每批最多处理 200 条原文，界面提供进度、暂停、继续和重建。索引为派生数据，原始消息独立保存。Android 使用原生历史查询与搜索实现。

百万级历史优化覆盖累计数据的打开、阅读、滚动、搜索、编辑和继续对话；单轮上下文按模型预算选取。

## 上下文与长期记忆

上下文由角色与人格、世界设定、近期原文、摘要、长期事实和检索资料组成，并预留输出空间。Web 的资料检索还包含 Data Bank 分块，按全局、百科、角色与会话作用域收集内容。

Web 删除原文或修改上下文参与状态时，同事务回退相关自动摘要、事件及后续整理进度。v2 摘要保存前重新检查来源与进度。

Android 自动事件最多复核 20 条来源、批量保存 5 条结果，提交时进行去重与来源检查。自动摘要先读取一致快照，模型返回后复核故事线修订、原文与前段进度，再保存新分段。撤回消息时回退受影响故事线的摘要尾部。

后续记忆工作见[优化目标](../docs/PRODUCT_GAP_MAP.md)。

## 创作与生成记录

Web 生成记录将任务状态、已保存步骤和操作按钮分区展示。暂停提交显示进行中状态，失败在对应任务内提供重试；失败详情默认折叠，展开后独立滚动。长记录列表支持完整滚动，窄屏保留底部导航所需空间。

生成结果中的世界正文与条目正文提供展开阅读和复制全文。长正文默认显示预览，展开后在有限高度内滚动，支持键盘操作；收起时回到正文开头，复制失败可原地重试。

Web 保存生成结果的进度与失败状态按记录保留。应用内切换页面再打开同一记录，可继续查看保存状态或重试；保存完成后更新结果缓存，过期的详情读取不会覆盖已保存状态。

生成记录与结果读取支持请求取消；离开结果页时停止当前详情请求，查看详情期间暂停记录列表轮询。保存请求独立于详情读取，页面内返回不取消保存。

百科详情支持重命名，保存期间显示处理状态，失败保留输入供再次提交。

生成记录提供分类、进度、详情与结果入口。暂停在当前步骤保存后生效，续跑使用已保存进度；取消保留已经生成的内容。

Android 记录操作支持窄屏换行。详情以底部面板展示，长反馈可滚动、选择复制，关闭与结果入口固定在底部。

Web 世界生成与文本整理使用异步模型调用，任务记录保存输入、检查点和完整结果。列表通过 ID 游标分页，详情按需读取，结果可以保存到世界库。保存操作使用事务和任务标记处理重复请求，原始生成结果与后续编辑的世界模板分别保存。

任务运行期间使用本机文件锁标识执行所有者；异常退出后可恢复中断任务。创作草稿通过 IndexedDB 保存，离页交互提供继续生成或停止并离开。

Android 生成任务将条目、时间线与进度一并保存，暂停状态持久化，失败可从保存位置继续。

## 资料交换

Web 角色库支持 PNG/JSON 角色卡、JSON/TXT/DOCX 便携包和 PNG 链接导入。角色与详细资料在同一事务保存。格式映射见[角色卡与聊天记录兼容](docs/酒馆生态与角色卡兼容调研.md)。

Web 世界模板与 Lore 使用 v1 世界包，完整解析与冲突检查后统一提交。替换自定义模板保留同标识模板的数据库 ID，内置模板保持独立。

Web 与 Android 各自保存本地数据，跨端转移通过文件导入导出完成。数据库与交换格式升级采用版本化迁移。
