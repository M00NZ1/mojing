Android 故事置顶只更新置顶字段，失败可重试；失效的手动发言角色会在提交前拦截，保留输入、附件和引用。角色详情重新载入期间保持动作等待，避免重复开聊。条目、时间线与关系删除等待真实结果，同世界刷新不丢失删除状态；条目末页删空自动退回上一页。旧小说章节可直接改名，目录、正文与 TXT 共用标题识别。

Android 平台支持确认删除。删除非默认平台保留公共调用配置；删除默认平台后需重新配置，已有会话不会静默切换到其他供应商。平台保存或删除写入失败时恢复原配置；明确选择的平台 ID 随人物/旁白请求传给费用记录，同地址、Key 和模型的不同平台按各自价格计价。

Android 角色、世界和模板库删除后保留当前搜索、筛选与页码，末页删空回退上一页，旧删除结果不会重置新查询。聊天、角色、世界和模板的文件导出中离页需确认；继续导出留在当前页，停止会等待写入取消后再导航，导出结束仍显示成功或错误提示。

Android 事件按当前故事线检索标题与描述，可筛选待跟进或已解决；收藏支持检索全部已保存备注，编辑后更新结果并定位原文。新沉淀资料保存来源指纹，原文变化或退出采用上下文时显示核对提示；旧资料仍可读，并明确无法核验版本。

Android 用户纠正的作用范围与原文所在故事线分别处理。“整个对话”纠正在其他线查看来源时可打开原文所属线；原文已在当前线继承可见时保持当前线。来源失效保留纠正并提示重试。模拟器已验收自动摘要创建关联纠正、跨线来源定位、重进与来源消息失效；真实供应商对纠正的遵循仍需实际对话验证。

Android 旧世界模板可先预览再归入指定已有世界，默认保留世界字段及同名条目，选择字段才覆盖；仍可新建世界，取消不写入，变化后的预览需重新核对。对话资料中的角色状态入口可查看当前故事线自动状态并单独清除，不删除手动记忆、纠正或其他线状态；继续沿用现有 15 条用户消息更新节奏。

## 应用更新

Android 设置中的“关于与更新”展示当前版本，支持手动检查 GitHub 正式发布版。新版本显示更新说明与安装包大小，确认后通过浏览器下载适配设备的 APK。重复检查失败时保留上次找到的安装包与更新说明；成功检查用最新结果替换，缺少适配包时不沿用旧包。更新源为 `M00NZ1/mojing`，对普通用户开放更新需将发布仓库设为公开。

## 生成用量与模型价格

Web 设置用量按汇总、平台、模型请求逐级查看，明细采用独立页面。支持周期和成功状态筛选，汇总在 SQLite 聚合，模型请求使用记录 ID 游标分页；单次请求可展开查看输入、输出 Token、耗时、原币预估费用与来源对话。对话回复下方显示单条消息的生成耗时、Token 和费用。平台与模型价格按每百万 Token 配置，人民币与美元独立汇总；平台模型目录返回明确币种和计价单位时可读取价格并确认保存，未返回时手动填写。首次配置补算同平台同模型的未计价历史，修改价格时可选择是否重算历史。请求开始时保存价格快照，未配置价格显示费用未知。旧记录保留原金额与供应商归类，不推断平台。

Android 回复完成后在消息下方显示生成耗时、输入与输出合计 Token、预估费用。用量页面提供输入、输出、缓存 Token、平台及模型明细。平台返回的用量优先使用，缺少用量时按文本估算。

Android 模型设置按平台与模型分别保存输入、输出、缓存输入单价，单位为每百万 Token，支持人民币与美元。可通过当前平台接口读取明确的价格字段，也可手动填写。未配置价格的模型显示“价格待配置”；填写 0 表示免费。

Android 用量页按平台、模型、请求三级查看，展示请求次数、成功与失败、Token、费用及日期。每次网络尝试单独记录，重试和取消保留请求状态。费用保存请求开始时的原币单价快照。首次填写价格后自动补算当前平台、此模型的未计价历史；已有计价记录时，编辑页提供默认关闭的“同步更新历史费用”开关，开启后重算该平台与模型的历史费用，关闭则保留历史金额。消息底部与用量页同步显示更新后的费用。

Android 金额默认以人民币显示，可切换美元。自动换算使用欧洲央行公布的参考汇率，支持刷新及手动输入；没有汇率时保留原币显示。原币费用独立汇总，旧记录归入“历史记录（未记录平台）”。

## 产品结构

Web 创作中心集中呈现角色与世界。世界页面汇集百科管理、世界生成、导入和生成记录；旧工坊资料归入后使用世界资料编辑，完全一致的世界与条目复用已有记录，内容不同的同名资料分别保留。

界面参考 [Google 官方 Reply、Jetsnack](https://github.com/android/compose-samples)与 [Material 3 Expressive](https://design.google/library/expressive-material-design-google-research) 的信息层级和组件表达。Android 使用 Compose BOM 2025.10.01、Material 3 1.4.0 与定制 Compose 组件；Web 使用 React 与 CSS 语义变量、`color-mix()` 和 `@starting-style`，弹窗动效遵循系统减少动态效果设置。

首页按故事主入口、准备开场与故事集组织内容。创作空间以小说创作为主操作，角色与世界集中呈现，世界内提供工坊生成和旧资料整理入口。资料卡统一图形、标题、说明与跳转区域；故事列表保留两行标题和两行预览，将日期放入辅助信息。聊天顶部显示会话名，平台与模型位于输入框底行；输入区采用圆角填充表面，阅读模式可收起输入区。

Android 界面采用墨色底与青绿强调色，保留八套可选主题。输入框、按钮、面板和文字层级使用统一组件规范，底部导航为悬浮圆角布局，页面前进与返回采用轻位移动画。图标以留白山形与流动墨线为意象，Android 与 Web 使用同一组矢量图形；启动页标语为“以墨为界，入境如梦。”，配合柔光背景与分阶段入场。

公共输入框使用圆角填充表面与内部标签，按钮采用胶囊轮廓、弹性按压与圆角过渡。搜索支持直接清空，确认弹窗的长说明独立滚动。底部导航使用图标文字并排的胶囊布局与完整选中区域；启动页按图形、产品名称、英文标识和原标语排列。Android 心声采用主题次级正文色，正文、引用与场景描述遵循各自表面配色。Web 消息气泡采用主题正文色，自发消息使用低饱和度强调色底面。Web 默认主题使用墨绿配色，输入与按钮统一触控尺寸、错误状态和减少动态效果设置。

首页、百科及编辑页的模型配置提示使用统一入口卡片，说明完整换行，点击整张卡片进入设置的模型分类。设置页恢复当前主分类，个人资料草稿与分类保持一致；快捷入口的分类切换继续检查未保存资料。

个人资料的名字、设定和颜色通过一次后台写入保存，完成后显示成功状态。写入失败保留草稿并提示重试；保存期间的新编辑继续保留，头像独立更新。

首页空列表提供页面内开始入口；已有对话时显示悬浮新增按钮，列表底部预留操作空间。

Android 小说开篇支持实时正文预览、耗时与字数反馈、取消和失败重试。生成前的故事设定与世界、角色选择在本机暂存，重进可恢复或确认清空；失效的资料选择需重新选择或明确移除。本轮使用提交时的世界和角色设定，资料刷新不影响已提交的创作。生成途中保留有限长度的可复制预览；停止并离开前确认预览与创作设定已写入本机，写入失败时留在页面供复制或重试。进程重启后可查看已收到的预览、复制或按当前恢复的设定重新生成，预览不代表完整正文。完成结构校验后将会话与全部章节一并保存。完整生成结果先保存在本机，重进创作页后可预览正文、复制全文、继续保存或确认放弃；已保存结果可打开原会话或开始新作。平台限流、模型配置、连接中断及输出不完整提供对应提示。

通用长期记忆按明确的 JSON 字段结构生成，兼容代码围栏、常见响应包装及文本字段的字符串/数组形式。开篇与记忆为已适配的 DeepSeek 模型使用结构化输出参数，记忆配置独立输出预算。解析失败保留已有记忆，自动整理采用短暂冷却；手动重建和清空独立执行，记忆面板展示当前故事线的整理状态。

Web 主导航为对话、创作和设置。对话首页直接提供最近会话续聊、完整会话列表和新建入口；最近消息预览对应的故事线会随续聊链接打开。创作中心连接角色、世界与故事推演。

角色定义参与者，世界统一管理背景、玩法、叙事规则和百科知识，工坊提供生成与旧资料整理。Android 角色可独立开聊，无需先绑定百科；未绑定角色也可加入选定百科的会话。百科列表支持重命名。

Android 百科 JSON 导入显示已处理的百科和词条数量，完成后才确认保存；用户可取消尚未提交的导入，失败不会留下半份世界资料。

Android 百科条目保存有对话来源时，编辑页提供“查看对话原文”。原文支持滚动与复制，可进入来源故事线并定位对应消息，返回后继续编辑百科草稿。读取失败可重试，来源删除后保留百科内容；来源故事线已删除时提示返回百科。

Android 百科词条的未保存表单按百科与条目隔离暂存，新条目编辑路由也可恢复草稿；重新进入时先选择恢复或丢弃。首次保存后转到正式条目路由，保存期间的新修改继续保留；草稿清理失败在编辑页重试，放弃修改和前往模型设置先清理草稿。

Android 百科历史版本记录标题、摘要、正文、标签和扩展资料。载入仅替换这些文本资料，类型、确认状态、精选和封面保留当前值；检查后保存，旧快照保持并生成当前保存前的资料快照。

来源对话在原文定位完成后显示历史窗口；加载失败或消息缺失时提供重试和返回百科入口。

自动沉淀条目的原文预览展示来源计数，支持逐条浏览整理依据；每次读取一条消息，进入故事线时定位当前来源。部分来源删除不影响浏览其余记录，旧条目继续使用单条来源。

百科列表与编辑页统一展示确认状态，自动沉淀标为“对话推断”。Android 添加关系使用可搜索的条目选择面板，每页 50 项，显示名称、类型和当前选择。候选查询只读取 ID、名称和类型，支持翻页、失败重试与关闭取消读取。

Android 百科主条目按 ID 升序分页，每页 100 条。分类切换回到首页，编辑返回及页面恢复保留分类与页码；空页可返回上一页，读取失败可重试。批量扩展字段补全覆盖当前分类的全部条目，关系图仅按关联 ID 读取名称。

Android 沉淀资料按条目 ID 倒序分页，每页 100 条，支持上一页、下一页和读取失败重试。切换分类回到第一页，同一百科编辑返回后保留分页位置。沉淀资料支持全部、待核对、已确认筛选及数量显示；待核对包含所有尚未确认的条目。编辑页在正文前提供状态选择，核对来源后可设为“已确认”并保存，来源记录继续保留。返回百科时保留主标签与条目分类，并刷新保存后的内容。

Web 与 Android 沉淀资料支持列表内批量核对，可逐条选择或选择当前筛选下前 100 条待核对资料，一次确认最多 100 条。确认更新状态与时间，保留正文和来源；失败保留选择，切换筛选清空选择。Web 同时保存条目版本，状态与版本在同一事务中提交；列表使用紧凑分段筛选，长摘要显示三行，点击标题进入详情。

Web 沉淀资料按创建顺序由新到旧浏览，每页最多 100 条，支持上一页、下一页与读取失败重试。确认状态在查询时筛选；翻页清空选择并回到列表顶部。查询采用稳定 ID 游标，列表只读取标题、状态、来源与最多 480 字的摘要，正文通过详情加载。

从 Web 沉淀资料打开条目后，可通过“返回沉淀资料”恢复当前筛选、页码和条目位置。详情读取失败时保留同一返回入口；返回列表重新读取本页，切换百科清除浏览位置。

百科条目与关联资料按最新刷新请求更新。快速切换分类或重新打开百科时，旧查询结果自动失效；时间线、关系和沉淀资料的连续读取使用同一个百科 ID。独立时间线事件可编辑标题、描述、时间标签和排序，关联条目的事件仍通过原条目编辑。保存期间防止重复提交，草稿按世界与事件隔离，保存成功只清理本次草稿。关系列表展示完整备注，长备注可展开，图中显示简短提示。

Android 百科主列表只读取展示字段；宽屏选中条目后按 ID 读取正文，失效或读取失败可重试并刷新列表。低高度窗口通过现有标签和新建按钮保留操作，避免重复快捷按钮挤压阅读区域。此改动不代表已测得大型百科性能收益；长人设的旧 8000 字角色镜像仍有反向截短风险，正在独立修复设计中。

Android 角色人设与百科正文使用可展开的长文本输入框：默认最多显示六行，展开后最多十六行，其余内容在框内滚动。展开与收起保留当前编辑内容，保存沿用页面现有入口。

Web 角色人设与百科正文同样支持展开、收起及框内滚动。编辑区高度随屏幕限制，展开按钮支持键盘操作，保留原有字数限制与表单保存入口。

Web 角色 AI 补全支持停止和重试；切换角色或离开补全区域时取消本页请求。补全只合并人设字段，保留等待期间修改的其他资料；人设已被手动修改时保留当前草稿并显示提示。

Web 角色保存使用提交快照，保存期间新增的编辑继续留在草稿中，并保留未保存提示。重新进入角色编辑页后，旧页面的保存响应不覆盖当前草稿。

Web 角色头像上传提供处理中状态和失败重试提示。头像上传与立绘生成结果绑定发起时的角色及编辑页，保留处理中手动选择的图片和其他草稿内容。

Web 桌面对话消息菜单支持方向键循环选择、Home/End 首尾定位、Esc 返回操作入口和 Tab 离开菜单。移动端操作面板展示发送者与两行消息预览，关闭入口固定在顶部，操作区独立滚动。输入法选词期间保留菜单状态。

Android 消息操作面板同样保留顶部关闭入口、发送者和两行原文预览，操作列表独立滚动；生成期间继续按操作类型控制可用状态。操作面板与撤回确认统一使用可见正文预览，用户输入的结构标签按原文保留。

Android 消息编辑采用自适应底部面板，正文独立滚动，标题、关闭与保存入口固定显示。键盘弹出时收起操作说明，为正文保留空间；关闭或下滑退出已修改的草稿时提供放弃确认。保存继续创建编辑故事线。

消息编辑保存中显示提交状态并锁定编辑与退出；写入失败在面板内提示，保留草稿供重试。分支已写入而后续加载失败时显示“已保存”，保留错误说明并禁用重复提交。

## 模型与请求

Android 模型选择面板区分下次发送线路和最近请求模型。生成期间切换模型，从下一次发送生效；最近请求模型在当前页面中保留，便于对照。底部面板固定搜索与关闭入口，长模型信息和按平台分组的模型列表可滚动浏览。

返回对话时刷新模型名称。设置中的默认线路适用于未单独选择模型的会话；会话中已选择的模型保持独立。

记忆、事件、书签和搜索支持定位历史原文。记忆与事件的来源跳转在目标消息进入聊天窗口后才关闭资料抽屉；失败保留来源卡片并可重试。历史加载期间保留查找入口，加载完成后可继续定位。聊天窗口停在较早消息且未包含故事线末尾时，输入区提示当前位置并提供“回到最新”；正文和旁白草稿保留，回到最新后再发送或续章。

模型选择保存期间显示进度，成功后更新名称并关闭面板；失败保留选择面板并显示重试提示。

平台预设为 DeepSeek、OpenAI、硅基流动、Anthropic 和自定义。每个平台独立保存名称、地址、Key 与模型清单，支持多个同类平台配置。

模型发现使用对应平台的认证与列表接口，Anthropic 模型列表支持分页；模型名称也可以手动填写。Web 对话使用现有 Chat Completions 兼容客户端。

默认平台提供公共文字线路，角色可配置独立线路。聊天页手动选择模型后，会话选择优先，从下一次发送生效；同一轮角色与旁白使用固定线路快照。

切换服务商或修改接口地址时处理相应凭据，不复用其他平台的 Key。平台编辑与其他设置分别保存。

## 会话、消息与分支

Web 消息编辑失败时在弹窗内显示错误并保留草稿，可直接再次提交；编辑故事线保存后可从故事线入口打开。

对话输入区显示两行引用预览，可直接取消；再次引用回复时使用该回复自身的正文。

Android 消息复制、编辑与引用保留用户输入的字面标签；模型结构化回复按可读正文处理。

会话绑定角色、世界设定和人格。当前故事线控制可见消息、上下文、搜索范围与回复落点。编辑、回复版本和分支保留原始剧情。

Android 收藏定位当前采用的消息版本时打开历史位置；收藏的旧回复版本只读展示原文，可复制全文，不切换故事线或改变采用状态。来源故事线不可用但原消息仍在时也可只读查看。

Android 收藏列表每页读取 40 条，按收藏时间和 ID 从新到旧继续加载；预览只处理已加载页，气泡收藏标记只查询当前消息窗口。列表展示已加载条数，较早页读取失败可原位重试。收藏可查看、编辑与清空备注，长备注支持展开；编辑失败保留输入，关闭编辑面板后可继续草稿。备注只更新原收藏，不改变原消息、收藏时间或来源定位。

Web 删除消息前读取关联信息，提交时再次检查故事线、检查点和编辑来源。Android 撤回在 Room 事务中检查引用，并处理回复版本回退和带归属标记的同线生成媒体。操作完成后加载附近历史窗口。

Web 消息菜单提供上下文排除与恢复。该设置保留原文、搜索和导出，从下一轮请求生效。

## 历史与搜索

会话通过稳定消息 ID 分页读取，搜索定位使用目标附近的消息窗口。

Web 当前故事线搜索使用 SQLite FTS5 单字、双字索引与原文子串复核，也可按发言角色的当前姓名查找。结果按消息 ID 倒序分页，正文与姓名重叠命中只显示一次；首批结果先显示，总命中数随后独立补齐，较早页不重复整线统计。首次索引从近期历史分批推进，新增、编辑和删除通过事务记录变更，再增量更新索引。

索引整理每批最多处理 200 条原文，界面提供进度、暂停、继续和重建。索引为派生数据，原始消息独立保存。Android 使用原生历史查询与搜索实现。

Android 搜索可按正文或发言角色的当前姓名查找，沿用当前故事线的消息可见范围；结果显示当前角色姓名、用户称呼与会话旁白名，姓名随当前结果页轻量读取，角色已删除时显示通用称呼。仅角色名命中的结果投影最多 2,048 字正文作为摘要来源，正文关键词命中保留完整定位文本。打开命中后再加载完整原文与附近消息，姓名命中时说明匹配来源，返回结果时保留列表位置；原文页可将命中消息定位到聊天的有界历史窗口，继续阅读或对话。

百万级历史优化覆盖累计数据的打开、阅读、滚动、搜索、编辑和继续对话；单轮上下文按模型预算选取。

## 上下文与长期记忆

上下文由角色与人格、世界设定、近期原文、摘要、长期事实和检索资料组成，并预留输出空间。Web 的资料检索还包含 Data Bank 分块，按全局、百科、角色与会话作用域收集内容。

Web 删除原文或修改上下文参与状态时，同事务回退相关自动摘要、事件及后续整理进度。v2 摘要保存前重新检查来源与进度。

Web 自动整理按当前故事线累计 10–40 条消息触发，默认 12 条；每批至多读取 40 条。设置页和 API 使用同一范围，历史超限值按原先实际生效的 12 条读取。摘要和自动事件按片段覆盖本批完整原文，每轮最多进行 4 次逻辑模型调用；每段保存来源校验后的续跑点，后续可从未完成片段继续，原文或模型名变化则从头整理。重叠触发合并，记忆面板可查看状态并手动继续。全部段落成功且来源仍有效才一起保存正式结果；每批事件去重后最多保留 5 条，并关联原文消息。续跑点存于现有设置表，删除会话时清理，不修改正式消息或数据库结构。

Web 事件面板按当前故事线读取最近 40 条，按需加载更早记录，可从事件卡片定位来源消息。记忆面板打开期间自动刷新摘要；事件面板显示最近一页时自动刷新，加载旧页后可手动刷新。

Android 自动事件最多复核 20 条来源、批量保存 5 条结果，提交时进行去重与来源检查。自动摘要先读取一致快照，模型返回后复核故事线修订、原文与前段进度，再保存新分段。撤回消息时回退受影响故事线的摘要尾部。

Android 事件面板按故事线显示来源事件。继承事件的完成状态可在当前故事线独立覆盖，来源事件原文及来源线状态不变；新建子分支会继承创建点可见的显式状态覆盖，之后可各自推进。删除继承事件仍须回来源故事线。状态覆盖存于 Room 27 的独立表，旧事件无需改写。

Android 长消息摘要每轮回复前最多处理 4 段；未完成的分段进度和承接摘要保存在本机，后续对话或记忆面板的“继续整理”会校验来源后续跑。手动整理可停止，未满阈值会显示尚需的对话条数；切换故事线或修改原文会取消本轮整理。正式摘要只在整批完成时提交。记忆整理间隔设置显示并保存 10–2000 的实际生效范围。

Android 角色状态锚点按会话、角色和故事线隔离，每累计 15 条新的当前上下文用户消息尝试更新；失败时继续使用本线旧状态，下一个间隔再试。编辑、撤回、回复版本和上下文排除会使受影响故事线的旧状态失效，待重新提取。升级前没有故事线来源的旧状态仍保留在本地，但不会注入模型提示。

后续记忆工作见[优化目标](../docs/PRODUCT_GAP_MAP.md)。

## 创作与生成记录

Web 生成记录将任务状态、已保存步骤和操作按钮分区展示。暂停提交显示进行中状态，失败在对应任务内提供重试；失败详情默认折叠，展开后独立滚动。长记录列表支持完整滚动，窄屏保留底部导航所需空间。

生成结果中的世界正文与条目正文提供展开阅读和复制全文。长正文默认显示预览，展开后在有限高度内滚动，支持键盘操作；收起时回到正文开头，复制失败可原地重试。

Web 保存生成结果的进度与失败状态按记录保留。应用内切换页面再打开同一记录，可继续查看保存状态或重试；保存完成后更新结果缓存，过期的详情读取不会覆盖已保存状态。

生成记录与结果读取支持请求取消；离开结果页时停止当前详情请求，查看详情期间暂停记录列表轮询。保存请求独立于详情读取，页面内返回不取消保存。

百科详情支持重命名，保存期间显示处理状态，失败保留输入供再次提交。

生成记录提供分类、进度、详情与结果入口。暂停在当前步骤保存后生效，续跑使用已保存进度；取消保留已经生成的内容。

Android 记录操作支持窄屏换行。详情以底部面板展示，长反馈可滚动、选择复制，关闭与结果入口固定在底部。

Web 世界生成与文本整理使用异步模型调用，任务记录保存输入、检查点和完整结果。列表通过 ID 游标分页，详情按需读取，结果可以保存到世界库。保存操作使用事务和任务标记处理重复请求，原始生成结果与后续编辑的世界资料分别保存。

工坊世界生成任务运行期间使用本机文件锁标识执行所有者；异常退出后可恢复中断任务。工坊生成草稿通过 IndexedDB 保存，离页交互提供继续生成或停止并离开。

Android 生成任务将条目、时间线与进度一并保存，暂停状态持久化，失败可从保存位置继续。

## 资料交换

Web 角色库支持 PNG/JSON 角色卡、JSON/TXT/DOCX 便携包和 PNG 链接导入。角色与详细资料在同一事务保存。格式映射见[角色卡与聊天记录兼容](docs/酒馆生态与角色卡兼容调研.md)。

Web 世界模板与 Lore 使用 v1 世界包，完整解析与冲突检查后统一提交。替换自定义模板保留同标识模板的数据库 ID，内置模板保持独立。

Web 与 Android 各自保存本地数据，跨端转移通过文件导入导出完成。数据库与交换格式升级采用版本化迁移。
Android 角色库全量导出按既有排序分批读取角色，只读取当批所需的百科名称并流式写入 v2 JSON；密钥不包含在导出文件中。
Android 会话菜单可导入常见酒馆 JSON/JSONL 聊天记录；导入按当前故事线识别重复内容，检查和写入时显示数量并可停止，整批写入失败会回滚。
Android 会话菜单支持 `mojing_chat_media_bundle` v1 主线记录与媒体包：导出主线文字、图片、空正文派生行与有序语音附件，完整校验后追加到当前故事线；角色按目标参与者名称精确对应，包内父消息关系保留，同包不重复写入。导出通过独立只读 WAL 快照分批读取，停止或离页等待清理完成后释放操作归属。该包不包含其他故事线、世界、角色卡或长期记忆，与 Web 会话交换格式独立。输入/解压总量上限 8 GiB，单媒体 512 MiB，媒体最多 16,384 个，单 JSON 元素与 ZIP 中央目录各 16 MiB；这些限制不代表百万级历史性能已实测。

### 开局选择与设置

新开局统一选择世界，同时取得背景、规则与百科知识；未整理的旧模板作为兼容资料保留。Android 与 Web 在只有一名角色时默认选中，多名角色时手动选择。Android 切换百科时保留兼容的已选角色，移除不兼容项；新出现的角色不会自动加入，手动清空的选择保持为空。

Web 开局提供旁白、剧情选项与规则约束开关，初始读取默认设置，本次选择优先。创建失败在表单中显示错误并保留选择；窄屏表单独立滚动。角色名单失效时停止创建，通过“刷新角色列表”移除不可用项并保留其他选择；创建结果返回实际参与人数。

### 对话与创作设置

个性化姓名与自我描述参与聊天、旁白和小说创作上下文。外观设置提供对话字体、旁白斜体与预览，偏好保存在本机。小说创作支持风格预设和自由输入；百科详情支持直接重命名，批量生成数量默认 1。

对话流式接收不设置固定总时限。OpenAI 兼容流需收到结束标记或明确的正常完成原因，连接提前关闭或输出达到上限时不会把半截回复保存成完整回复。人物与旁白连续 5 分钟没有正文时结束等待；持续输出可超过该时长。角色与旁白在中断后保留已收到的正文，可从已有内容继续对话。

## Android 对话阅读

- 顶栏集中显示会话名；平台与模型位于输入框下方，选择对下一次发送生效。
- 阅读模式收起输入区并扩展正文，悬浮按钮支持继续对话和回到最新。
- 消息长按进入文字选择页，可选择段落或复制正文。
- 小说目录按当前故事线分页列出章节和续写片段，可搜索标题、已记录的章节编号和开头片段；编号支持 `12`、`十二`、`第十二章`。查询覆盖未加载目录，沿用已采用回复范围；正文全文查询使用独立消息搜索。目标原文进入聊天窗口后才关闭目录，读取失败时保留目录并可重试；清除搜索恢复目录，续章与 TXT 导出继续作用于当前故事线。
- 搜索独立成页，保存最近搜索，显示日期、匹配片段与高亮。结果最多缓存连续 120 条，可双向按消息 ID 翻页并显示结果区间；只读消息窗口提供跨页的上下结果导航、绝对序号和总匹配计数。
- 完整回复记录生成耗时；朗读支持微软 Azure、系统默认与已安装的第三方 TTS 引擎，对话选择音色、角色独立配置、长文本分段与停止播放。对话朗读期间显示状态和停止入口，系统朗读在末段完成后结束状态。朗读失败可直接重试完整正文与本次原音色；停止、换音色、切故事线或离页后不沿用旧失败请求，后台生成离页后也不会重新开启朗读。切线读取与音色保存期间暂不启动朗读。音色列表提供独立试听和停止，试听不修改已保存选择；切换引擎、选择音色或离开面板时取消试听。

### 模型快捷选择

Android 对话输入区的模型入口按平台展示目录。平台标签支持横向滑动，选中平台后显示其模型，点击模型保存为下一次发送使用的线路。聊天与默认模型选择采用紧凑面板，搜索默认收起，点击图标展开；平台 Key、模型选择与费用配置保持独立。

### 小说阅读与续章

Android 小说目录支持修改书名、命名章节、生成下一章和 TXT 导出。续章沿用当前对话的平台、模型、世界设定与记忆；未完成章节保留草稿，可继续生成。导出包含当前故事线的章节与正文续写片段。日常对话与剧情走向输入继续保留。

聊天回复下方直接显示生成耗时、Token 与费用。顶部保留已加载消息的 Token 估算。搜索原文复用聊天消息组件，在长消息内部定位并高亮关键词。

### 平台设置与用量明细

Android 平台设置使用横向切换标签，选中平台的连接信息、默认模型和价格显示在下方。平台编辑按连接配置与模型目录分组。模型选择列表提供边界与选中标记。

用量按平台、模型、请求逐级查看，二三级使用独立页面。模型列表支持按最近使用、Token、请求数排序；请求记录支持状态筛选和 Token 排序。
