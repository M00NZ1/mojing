# MoJing 当前项目状态

更新日期：2026-09-07

本文是适合公开仓库的短状态说明，不记录个人设备、绝对路径、会话数据、密钥、一次性施工过程或逐提交日志。

## 当前产品

- 产品名称：墨境 MoJing；
- 正式源码根：`mojing/`；
- Web：React/Vite；
- 本机 API：FastAPI/SQLAlchemy/SQLite/文件存储；
- Android：Kotlin/Jetpack Compose/Room；
- Android 标识：`com.mojing.app`；
- 运行边界：本地优先、单用户、无账号体系、无自动云同步。

## 当前能力

- 角色、人格、百科、WorldInfo 和世界模板；
- 单角色/多角色会话与流式回复；
- 停止、重试、继续生成、非破坏性编辑和剧情分支；
- 会话草稿、历史分页、全文搜索、收藏定位；
- 上下文预算、摘要、长期记忆与来源；
- 图片、语音、附件和本地导入导出；
- Web 与原生 Android 两条客户端路线。

## 当前历史搜索

- Web 当前故事线搜索使用本机 SQLite FTS5 派生索引，支持中文单字/词组、中英混合、大小写折叠及标点、百分号、下划线的字面匹配；复用既有分支可见性规则；
- 结果按消息 ID 倒序，每页 25 条，可查看更早/较新结果并跳到未加载原文；只加载目标附近消息窗口，失败保留结果供重试；
- 首次搜索从最近历史开始分批整理，显示未完成状态，可暂停、继续或关闭后重进。原文新增、编辑、删除和批量恢复在同一事务记录变化，搜索时分批更新；不逐次全量重建；
- 索引格式 v1，索引与处理游标同事务提交；索引缺失或捕获触发器缺失时重新回查，未知版本不覆盖。高级入口可重建本机索引，原始消息不改变。原文写入不依赖 FTS 或 Python 索引函数；
- Android 仍沿用其原生搜索实现，本批没有改 Room 或跨端交换格式。旧 Web 搜索 API 保留，修复通配符误匹配，但旧调用方仍走 LIKE 扫描。

## 当前模型配置

- Android 对话平台独立保存名称、地址、Key 与多个模型；旧单平台配置按 v1 格式惰性迁移，读取异常时保留原数据；
- 预设仅保留 DeepSeek、OpenAI、硅基流动、Anthropic、自定义；Web 对应预设同步收敛；
- 模型可通过平台接口获取，Anthropic 使用原生认证和分页；不支持时可手动输入多个名称；
- Android 聊天页按平台分组选择模型，保存到本会话，从下一次发送生效；正在进行的回合固定原线路；
- Android 可保存多个同类平台配置；切换预设不沿用其他服务商的 Key，保存默认平台时同步既有公共线路消费者；
- Web 已支持独立平台保存、默认平台、模型获取/手填与会话模型选择；选择在下一次发送生效，所选线路在整轮角色/旁白请求中固定；模型选择列表按可见窗口渲染；
- Web 旧公共配置保留，新平台目录作为默认文字线路唯一来源；更换地址不能沿用已保存 Key，角色自定义地址也不能借用其他平台的公共 Key；
- Web 设置页区分平台保存和其他设置保存，未保存的平台编辑受离页/标签切换保护，小屏标签保持完整并显示当前分类。

## 当前创作库与生成记录

- Android 新内置资料为“雾港来信”：一个百科、一个世界、沈照与林汐两个角色；百科含七个基础条目及两个角色镜像；
- Web 新目录与 Android 内容一致；创作中心提供“从雾港开始”，一次带入世界、百科与两名角色。正式数据源位于 `mojing/data/builtin_pack/starter_catalog.json`，Android raw 分发副本通过内容一致性测试约束；
- Web 一次性安装目录，不再在启动时补回旧角色、覆盖旧世界或补充旧百科。只收起与旧版参考完全一致、无已知引用或默认配置引用的旧示例；原始行保留，已修改或使用的资料继续显示，创作中心可恢复旧示例；
- 原样、未被使用或配置引用的旧示例通过同一 Room 事务归档并替换；任一自定义内容、历史引用或跨百科关联会阻止移除；旧版资源只用于识别/恢复，不再作为初始化目录；
- 示例按 `builtin_catalog_v2` 只初始化一次，删除后重启不会补回；新目录写入失败时旧目录移除一起回滚；
- Android 角色统一为置顶、收藏、创建时间倒序；百科筛选保持同一顺序，编辑不再改变普通角色位置；
- Web 角色库提供独立导入窗口，统一 PNG/JSON 角色卡、便携包与链接入口；导入后可直接查看角色，新建/查看导入结果清空旧搜索，未保存编辑仍受保护；列表按收藏、创建时间、ID 倒序稳定排列；
- Web 便携角色与详细资料同事务导入，失败回滚；TXT/DOCX 便携导出保留 profile，DOCX 读取保留段落、换行与 XML 转义正文，零温度参数可往返；PNG 上传不再共用临时路径，上传及链接读取限制 32 MiB，链接连接/读取设置 30 秒超时；
- 生成记录按进行中/需处理/全部浏览，展示进度、详情和结果入口；取消需确认，已生成内容保留；
- 暂停状态持久化，在当前步骤落库后暂停；失败重试保留进度，百科条目/时间线内容与进度同事务保存；取消不会被晚到的完成状态覆盖；
- Web 世界生成和文本整理的完整结果保留在原任务记录；刷新后可从独立“生成记录”入口找回、按需读取详情并保存到世界库；旧记录没有完整结果时明确说明；
- Web 记录使用 ID 游标分页，每页 20 条；详情中的 Lore 每页 20 条，支持读取/保存失败重试、深链刷新与返回；成功状态统一使用 `succeeded`；
- 保存记录结果支持重复/并发请求；标识冲突不覆盖已有世界，世界与保存标记同事务提交；结果详情保留原生成正文，“管理此世界”读取现有模板数据，已删除模板可重新保存；
- Web 世界生成/文本整理使用可取消的异步模型调用；停止或明确离页会取消当前请求并关闭客户端，后续步骤不会继续；记录显示“已停止”，成功记录不会被晚到的停止覆盖；
- Web 生成中离页提供“继续生成 / 停止并离开”；结果完成时关闭过期确认框。生成与导入草稿通过 IndexedDB 异步保存，停止/重进后恢复；存储失败、未知格式和多页面冲突不覆盖已有草稿，页面输入保持可编辑；
- Web 世界生成与文本整理的新任务保存 v1 输入和分步检查点；暂停在当前步骤落库后生效，重进/失败续跑跳过已保存的命名、世界骨架、Lore 或文本片段/合并结果；停止仍为取消，与暂停分开；
- 新任务由现有 JobRun 记录管理，执行期间持有与数据库对应的本机文件锁；启动、记录或进度读取时仅恢复可确认没有执行所有者的新任务，旧记录缺失输入/所有权证据时不自动改写；
- 新任务的在线调用失败不再静默换成本地骨架成功；一次执行固定解析后的线路，续跑的剩余步骤使用当前线路配置。列表只读取进度摘要，不传输完整原文或中间结果；

## 当前世界资料转移

- Web 世界导出始终通过本机 API，单个世界与自定义合集的入口不再被模型供应商地址隐藏；失败后可重试；
- 世界模板包先校验完整结构、版本、数量和冲突，再在同一事务中导入；导入内容与成功记录一起提交，失败记录不再带入未完成的数据修改；
- “替换全部自定义模板”保留同标识模板的数据库 ID，仅移除包外自定义模板；内置模板不可覆盖，预览与实际写入一致；
- 沿用 v1 交换格式，无数据库 schema 变化；旧包缺省版本及可选字段保持兼容。

## 数据边界

- Web 数据位于本机 Backend 的 SQLite/文件存储；
- Android 数据位于应用私有 Room/文件存储；
- 两端不共享运行时数据库，跨端通过版本化导入/导出交换；
- `.env`、API Key、数据库、媒体、日志、备份和本机配置不进入 Git；
- 原始消息、角色、设定、分支和手动记忆不可用清缓存方式处理。

## 当前证据边界

仓库包含 Backend、Web 和 Android 自动测试与构建入口，但公开状态文档不把旧运行记录当作当前验证。每次变更应在任务报告或 CI 中分别记录：

- 自动测试；
- Web/Android 构建；
- 浏览器真实运行；
- 模拟器运行；
- 真机运行；
- 大型数据/性能测试；
- 用户报告；
- 尚未验证项。

## 兼容变化

本次命名收口把正式源码目录、内部项目标识和 Android namespace/application ID 统一到 MoJing。早期预改名 Android 构建不会被原位覆盖；旧数据应通过显式导出/导入迁移，旧应用和数据在用户确认前不得自动删除。
