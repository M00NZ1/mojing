# MoJing 当前项目状态

更新日期：2026-09-07

本文是适合公开仓库的短状态说明，不记录个人设备、绝对路径、会话数据、密钥、一次性施工过程或逐提交日志。

## 当前产品

- 产品名称：墨境 MoJing；
- 正式源码根：`mojing/`；
- Web：React/Vite；
- 本机 API：FastAPI/SQLAlchemy/SQLite/文件存储；
- Android：Kotlin/Jetpack Compose/Room；
- Android 标识：`com.mojing.app`；
- 运行边界：本地优先、单用户、无账号体系、无自动云同步。

## 当前能力

- 角色、人格、百科、WorldInfo 和世界模板；
- 单角色/多角色会话与流式回复；
- 停止、重试、继续生成、非破坏性编辑和剧情分支；
- 会话草稿、历史分页、全文搜索、收藏定位；
- 上下文预算、摘要、长期记忆与来源；
- 图片、语音、附件和本地导入导出；
- Web 与原生 Android 两条客户端路线。

## 当前模型配置

- Android 对话平台独立保存名称、地址、Key 与多个模型；旧单平台配置按 v1 格式惰性迁移，读取异常时保留原数据；
- 预设仅保留 DeepSeek、OpenAI、硅基流动、Anthropic、自定义；Web 对应预设同步收敛；
- 模型可通过平台接口获取，Anthropic 使用原生认证和分页；不支持时可手动输入多个名称；
- Android 聊天页按平台分组选择模型，保存到本会话，从下一次发送生效；正在进行的回合固定原线路；
- Android 可保存多个同类平台配置；切换预设不沿用其他服务商的 Key，保存默认平台时同步既有公共线路消费者；
- Web 已支持独立平台保存、默认平台、模型获取/手填与会话模型选择；选择在下一次发送生效，所选线路在整轮角色/旁白请求中固定；模型选择列表按可见窗口渲染；
- Web 旧公共配置保留，新平台目录作为默认文字线路唯一来源；更换地址不能沿用已保存 Key，角色自定义地址也不能借用其他平台的公共 Key；
- Web 设置页区分平台保存和其他设置保存，未保存的平台编辑受离页/标签切换保护，小屏标签保持完整并显示当前分类。

## 当前创作库与生成记录

- Android 新内置资料为“雾港来信”：一个百科、一个世界、沈照与林汐两个角色；百科含七个基础条目及两个角色镜像；
- 原样、未被使用或配置引用的旧示例通过同一 Room 事务归档并替换；任一自定义内容、历史引用或跨百科关联会阻止移除；旧版资源只用于识别/恢复，不再作为初始化目录；
- 示例按 `builtin_catalog_v2` 只初始化一次，删除后重启不会补回；新目录写入失败时旧目录移除一起回滚；
- Android 角色统一为置顶、收藏、创建时间倒序；百科筛选保持同一顺序，编辑不再改变普通角色位置；
- 生成记录按进行中/需处理/全部浏览，展示进度、详情和结果入口；取消需确认，已生成内容保留；
- 暂停状态持久化，在当前步骤落库后暂停；失败重试保留进度，百科条目/时间线内容与进度同事务保存；取消不会被晚到的完成状态覆盖；
- 本批未改动 Web 内置目录、角色排序或生成记录交互。

## 最近验证范围

- Android：86 个 JVM 测试套件、444 项测试通过；主代码及 AndroidTest Kotlin 编译通过；
- SQLite：5 项桌面回归通过，覆盖 DAO 排序、进度续跑、终态保护与迁移引用查询；
- Web 模型配置批次：TypeScript `--noEmit` 检查通过；47 项定向 Backend 测试覆盖配置、迁移、请求快照、备份、分支及取消；
- Chrome 无头浏览器使用隔离模拟 API，通过桌面 1365×900 / 窄屏 390×844 的平台保存、重进、Key 清除、手填、获取失败/取消、离页保护、选择失败重试与发送；5,000 模型的搜索/选择与可见节点数量检查通过。这是实际浏览器交互证据，不是真实供应商或完整本机服务联调；
- 未执行 APK 打包、安装、设备测试、真实供应商请求或大型会话性能测试；旧示例升级/恢复的 Room instrumentation 已更新并编译，尚未设备运行；
- 本批只修改正式源码与文档，没有操作正式数据库、用户会话、媒体、Key 或本机配置。

## 数据边界

- Web 数据位于本机 Backend 的 SQLite/文件存储；
- Android 数据位于应用私有 Room/文件存储；
- 两端不共享运行时数据库，跨端通过版本化导入/导出交换；
- `.env`、API Key、数据库、媒体、日志、备份和本机配置不进入 Git；
- 原始消息、角色、设定、分支和手动记忆不可用清缓存方式处理。

## 当前证据边界

仓库包含 Backend、Web 和 Android 自动测试与构建入口，但公开状态文档不把旧运行记录当作当前验证。每次变更应在任务报告或 CI 中分别记录：

- 自动测试；
- Web/Android 构建；
- 浏览器真实运行；
- 模拟器运行；
- 真机运行；
- 大型数据/性能测试；
- 用户报告；
- 尚未验证项。
