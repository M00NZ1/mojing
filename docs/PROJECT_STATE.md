## 当前功能

### 角色与世界

初始目录为“雾港来信”：一个百科、一个世界、沈照与林汐两个角色。百科包含七个基础条目和两个角色条目，Web 创作中心提供配套开局入口。

示例目录只初始化一次。旧示例按内容与引用识别后归档，保留恢复入口；已修改或被引用的资料继续保留。

Web 角色按收藏、创建时间、ID 倒序排列；Android 按置顶、收藏、创建时间排序。角色导入提供 PNG、JSON、便携包与链接入口，Web 导入完成后可直接打开角色。

Web PNG 角色卡导出保留完整角色设定，支持 PNG、JPEG、WebP 头像并处理图片方向。下载按钮显示导出状态，修改保存后可导出。

### 模型平台

两端支持多个独立平台配置，每个平台保存名称、地址、Key 和模型列表。预设为 DeepSeek、OpenAI、硅基流动、Anthropic 和自定义。

模型列表支持接口获取和手动填写。聊天页按平台分组选择模型，会话内保存选择，从下一次发送生效；当前生成使用启动时确定的线路。

Web 与 Android 获取模型时保留已有列表顺序，追加新模型并去重，保留手动模型名和默认选择，显示本次新增数量。

Android 平台编辑在返回、取消和点击弹窗外侧时检查未保存修改，支持继续编辑或放弃修改。

Android 默认模型选择支持名称搜索、当前选中标记和懒加载列表，取消选择保留原配置。

### 生成记录

生成记录集中展示状态、进度、详情和结果入口。暂停在当前步骤保存后生效，继续执行复用已保存进度，取消保留已生成内容。

Web 世界生成与文本整理将输入、检查点和完整结果保存在任务记录中，支持刷新找回、分页浏览、续跑及保存到世界库。创作草稿通过 IndexedDB 保存。

### 对话与历史

会话支持流式回复、停止、重试、继续生成、消息编辑、回复版本和故事线。历史通过分页与消息窗口加载，搜索结果可定位到旧消息。

Web 当前故事线搜索使用 SQLite FTS5 增量索引，支持索引整理、暂停、继续与重建。消息菜单支持排除或恢复上下文，原文继续保留在历史与搜索中。

Web 搜索结果展示两行摘要并突出显示匹配文本，支持从结果直接定位到历史消息。切页或切换搜索范围时回到结果顶部，同页刷新保留阅读位置。

Android 搜索按会话、故事线和请求序号管理结果。修改关键词、切换匹配方式与关闭搜索会取消旧请求；完成搜索后显示结果或空结果提示。

Android 搜索摘要围绕关键词截取，后台完成正文整理并保留 Unicode 字符边界，结果沿用关键词高亮与历史定位入口。

Android 搜索按消息 ID 向更早方向翻页，每页最多一百条，支持返回最新结果，主线与其他故事线沿用相同分页方式。

Web 删除与 Android 撤回在提交时检查故事线、检查点和编辑来源，完成后保持附近历史位置，并更新相关自动记忆。

### 自动记忆

Web 删除或切换上下文参与状态时，回退受影响的自动摘要和事件进度。后台摘要保存前重新检查来源与整理进度。

Android 自动事件按当前故事线读取，批量提交前复核来源；摘要使用一致快照并检查修订与进度，撤回原文时回退相关故事线的摘要尾部。

Android 切换或重生成回复时，同事务回退当前故事线受影响的分段摘要。编辑来源与回复选择共同控制继承摘要的可见范围，后续对话从有效进度重新整理，记忆面板随消息刷新。

Android 长消息摘要按预算分段读取完整正文，逐段整合剧情与关键事实，全部处理完成后保存。聊天输入区显示记忆整理段数，支持停止；失败或取消保留原整理进度。

Android 自动百科整理将对话事实保存为推断条目，保留会话、故事线与原文来源。保存前复核来源和百科设置，整批写入并过滤同批重复内容。角色设定通过角色编辑入口管理。

对话来源的独立条目在编辑页显示“对话资料”。确认、改名、调整类型和再次保存均保留条目身份，同名角色及其设定保持独立。

Android 百科编辑按一次提交处理保存，历史快照与正文在同一事务中写入。保存期间保留后续输入，失败后可直接重试；已删除条目停止写入，未修改条目保持已保存状态。

百科历史版本每页展示十条，支持查看更早版本、返回最新版本和载入编辑；翻页保留当前草稿。载入历史前确认替换未保存修改，保存与生成期间暂停载入操作。
