## 对话流式生成

Android 角色回复与旁白不再设置两分钟总时限，网络层保留连接与读取超时。收到部分正文后发生网络错误时，将最新正文保存到当前故事线；重生成保留回复版本关联，并提示可继续对话。

回归覆盖角色与旁白持续 140 秒后完成、持续 140 秒后断线，以及最后增量正文保存；使用协程虚拟时钟执行 ViewModel 自动测试。
