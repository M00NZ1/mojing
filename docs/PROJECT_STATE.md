## 故事生成与记忆整理

Android 小说开篇采用流式正文预览，显示当前模型、已用时间、首字时间和正文长度。等待、接收、重试、校验与保存分别反馈；停止或失败保留输入和已接收预览，完整正文通过校验后写入会话。请求错误按平台状态、网络和输出完整性分类，日志记录请求阶段与耗时。

Android 开篇将会话、世界配置、角色与全部章节放入同一 Room 事务。完整正文和生成时的设定先保存为本地草稿，退出页面或重启应用后可继续保存、复制全文或确认放弃。草稿与会话通过同一事务交接，已保存结果复用原会话；恢复入口位于创作页顶部，提供正文预览与开始新作。

小说生成固定使用提交时的世界与角色设定；生成期间刷新资料不会丢弃已完成正文或隐藏请求错误。用户实际修改输入后，旧请求结果按输入修订隔离。

通用记忆提示词明确对象、数组及字段类型；解析支持代码围栏、常见响应包装和文本字段的字符串/数组转换。开篇与记忆请求为已适配的 DeepSeek 模型启用 JSON 输出及非推理模式，记忆使用独立的 3,200 Token 输出预算。自动整理失败后短暂冷却，手动重建与清空可立即操作。记忆面板显示本次整理状态，后台结果按故事线隔离。

Android 35 模拟器通过真实平台接口完成单章、双章、返回正文前后取消、无效模型修正后重试，以及记忆重建和清空。最近一轮开篇样本：DeepSeek `deepseek-flash` 单章 2,071 字 / 12.1 秒、双章 3,820 字 / 18.8 秒；硅基流动 `Pro/deepseek-ai/DeepSeek-V3.2` 单章 2,952 字 / 99.2 秒、双章 7,000 字 / 276.3 秒。相同故事记录的记忆重建分别为 4.8 秒和 123.1 秒。生成篇幅仍随模型变化，继续优化长度控制。

Web 小说创作显示草稿保存状态，存储失败可重试，跨页面修改和无法读取的旧草稿需确认后替换。生成成功仅清理本次提交的草稿修订；窄屏表单独立滚动，底部生成按钮保持可达。 Web 生产构建与隔离 Edge 的 7 组草稿交互回归通过；浏览器回归使用模拟 API。

Web 开篇提交编号随草稿保存；刷新或响应中断后可继续本次创作，已完成的请求直接打开原会话。修改设定会使用新编号。后端将完成回执与会话、章节放入同一事务，已删除的原会话不会被重新生成。 15 项后端与迁移测试、Web 构建和浏览器模拟接口回归通过，隔离数据库已沿 Alembic 迁移链升级至 `20260913_0013`。

Web 完整开篇正文先暂存，再创建会话。会话保存失败或完整正文到达后停止时，可重新进入页面预览、复制和继续保存；保存成功后交接至会话，确认放弃仅删除暂存正文。23 项后端与迁移测试，以及浏览器模拟接口回归通过。

## Android 搜索索引就绪状态

首次迁移或搜索索引版本更新时，未建索引正文的 SQLite 回退比较与 NFKC 规范化不一致，会漏掉全角等兼容字符。搜索页等待索引就绪，期间显示整理状态，允许返回或修改关键词；完成后才发布完整命中和精确总数，整理失败保留重试。原消息、FTS 表、Room schema 与双向游标分页保持不变。搜索首次等待时长取决于未整理历史规模；尚需在设备和大型数据上测量。

## Android 分支搜索就绪屏障

正常 15→16 数据库迁移和新建故事线都在事务内生成可见区段；但已有派生区段缺失或过期时，后台启动修复与非主线搜索可能并发，搜索会把修复前的空结果或错误可见范围当成完整结果。非主故事线搜索现在先等待进程内单一修复任务成功，再整理消息索引和发布结果；失败时保留重试入口，主线搜索不等待该修复。修复仍复用原事务，不改原消息、表结构或迁移。

管理器失败重试与搜索页面等待、取消、失败重试及主线不阻塞的定向 JVM 测试通过。本批未重新打包；上节 APK 仍是上一批产物。尚无设备上的损坏派生区段恢复实测，也未测量大量故事线时的首次修复耗时。

## Android 对话入口故事线就绪

恢复上次打开的非主故事线时，旧实现可能先读到尚待修复的空可见区段，把已有消息显示为新对话，后续生成也会缺失这段历史。会话包含分支时，聊天初始化现在先等待同一个可重试的可见性修复任务，再读取消息、摘要、事件和回复恢复位置；失败仍停留在现有加载错误与重试状态，不发布空时间线。无分支主线不增加等待，新建分支沿用原事务维护区段。

ChatViewModel 定向 JVM 测试通过，覆盖非主线初始化等待、失败重试、消息与摘要/事件读取门槛，以及无分支主线不阻塞。本批未重新打包或运行设备；现有 APK 不包含此批改动。设备上的旧派生区段恢复和大量分支首次等待时间仍待验收。
