# 墨境持续优化目标

持续优化墨境的角色扮演、长篇对话和世界创作体验，完善 Web 与原生 Android 的功能衔接、界面设计、本地数据管理和大型历史性能。

正式源码位于 `mojing/`。

## P1：剧情与记忆一致性

- 完善 Android 旧摘要空洞整理与大型历史的增量重整。
- 将 Android 消息的上下文参与状态与回复版本选择分离，提供独立的排除、恢复入口。
- 完善百科推断条目的来源变更提示与长文本整理；Web 与 Android 已支持每批最多 100 条确认。Web 与 Android 沉淀资料已采用游标分页，Android 主条目列表已分页，关系选择器已采用精简字段搜索分页，关系图按关联 ID 读取名称；继续完善大型关系图与时间线浏览。
- 优化长消息摘要的检查点续跑与批次调度。
- 统一消息操作后记忆、事件、历史窗口与详情面板的更新。
- 完善生成任务的暂停、继续、取消、重进恢复与结果管理。

## P1：当前反馈跟进

- 对照用户的模型切换入口与实际请求，完善会话选择、默认线路及当前生成模型的可见反馈。

- 跟进首次单章生成的实际反馈，完善多章节生成与续写的失败恢复。
- 进一步连接百科知识、工坊玩法与开局选择，提供一致的跨端入口。
- 补齐 Android 滑动收回、不同主题及小屏长消息的设备回归。

## P1：核心界面与交互

- 优先统一对话消息的复制、编辑、重试、版本与分支操作，整理会话资料面板及 Web 对应入口。
- 在统一输入框、按钮、导航和品牌视觉的基础上，继续完善对话、角色、世界、模型配置和生成记录的页面布局与信息层级。旁白面板已区分自动生成与指定方向，采用纵向操作旁白方向与配图描述接入按会话本地草稿，写入对话后清空本次输入；配图长输入已限制可见高度。
- 完善小屏、键盘、系统返回、旋转、分屏和字体缩放适配。
- 统一加载、空状态、错误、重试、保存和取消交互。
- 改进草稿恢复、深链进入、前进后退和跨页面结果定位。
- 完善平台切换、模型发现、请求停止、超时与限流反馈。

## P2：大型历史

支持单个会话累计几十万至上百万 Token 后的流畅打开、阅读、滚动、搜索、编辑、定位和继续对话。单轮请求按模型预算组合活动上下文。

- 控制消息加载页、可见窗口与内存缓存规模。
- 优化长文本、动态图片高度、连续分页和搜索跳转。
- 完善中文、中英混合、短语与标点搜索。
- 提升多会话、多分支和频繁编辑场景下的增量索引效率。
- 优化索引整理、重新构建与历史重新摘要的进度控制。
- 建立打开、滚动、搜索、定位、内存和数据库体积的性能基线。

## P2：长期记忆

- 完善角色知情范围、秘密、用户纠正和跨分支事实冲突处理。
- 统一摘要、长期事实、自动事件和百科沉淀的来源关联。
- 补齐旧派生数据的整理与失效处理。
- 优化固定设定、近期原文、检索结果与输出空间的预算分配。
- 提供清晰的记忆编辑、来源定位和上下文查看入口。

## P2：导入导出与迁移

- 统一角色、世界、会话、分支、记忆与媒体的版本化交换契约。
- 完善角色卡拆分字段、备选开场白与世界书的导出映射。
- 优化导入预览、冲突处理、重复导入和结果定位。
- 完善大文件导入、取消恢复、格式升级与异常中断恢复。
- 改进 Web 与 Android 之间的资料迁移和本地备份流程。

## P3：可维护性

- 保持页面、状态管理、业务逻辑和存储职责清晰。
- 统一两端会话、消息、分支、错误和交换格式的语义。
- 随功能更新同步维护产品说明、接口说明和操作指南。
- 按完整功能流程安排迭代，同步完成界面、数据、测试与文档。
