# 墨境持续优化目标

持续优化墨境的角色扮演、长篇对话和世界创作体验，完善 Web 与原生 Android 的功能衔接、界面设计、本地数据管理和大型历史性能。

正式源码位于 `mojing/`。

界面更新覆盖一级、二三级、搜索结果、操作弹层及创建后的编辑流程，逐项范围见 [UI_COVERAGE.md](UI_COVERAGE.md)。

## P1：剧情与记忆一致性

- 完善 Android 旧摘要空洞整理与大型历史的增量重整。
- 将 Android 消息的上下文参与状态与回复版本选择分离，提供独立的排除、恢复入口。
  回复滑动监听已改为读取最新选择状态，避免滑回初始版本时漏保存；搜索只读浏览不改写版本选择。分页与导出已改为按故事线解析版本组的有效选择，避免跨页旧版本误参与上下文。独立上下文排除仍待实现。
  当前 `includeInContext` 同时保留旧版本默认与派生消息标记，显式回复选择会覆盖它；新增排除状态须独立于版本选择。小说目录和最大章节编号复用了上下文查询，需分离阅读选择与模型过滤，并同步失效受影响的自动摘要和通用记忆。
- 完善百科推断条目的来源变更提示与长文本整理；Web 与 Android 已支持每批最多 100 条确认。Web 与 Android 沉淀资料已采用游标分页，Android 主条目列表已分页，关系选择器已采用精简字段搜索分页，关系图按关联 ID 读取名称；继续完善大型关系图与时间线浏览。
- 优化长消息摘要的检查点续跑与批次调度。
- 统一消息操作后记忆、事件、历史窗口与详情面板的更新。Android 事件页已补充状态筛选、操作防重复和原位失败提示；继承事件在来源故事线管理，分支独立事件状态覆盖仍待完善。收藏已支持按来源故事线定位、成功后收起面板与失败重试；继续完善旧回复版本的只读定位展示，避免查看收藏时改写采用版本。
- 完善生成任务的暂停、继续、取消、重进恢复与结果管理。

- 世界设置已增加按世界隔离的编辑草稿及重进恢复、确认丢弃入口；角色编辑的返回与设置跳转已统一未保存确认，支持保存成功后离开；继续完善角色与百科编辑草稿恢复。

## P1：当前反馈跟进

- 跟随角色与模型设置时，Key 与接口地址按会话、角色、公共配置整组解析；角色线路测试与实际请求共用主模型和思考模型规则。角色专用线路不借用公共模型，旧会话专用连接沿用公共模型并显示说明；直接选择平台时使用该平台的模型。继续完善旧会话专用配置向平台选择的引导。
- 语音选择支持微软 Azure、系统默认和已安装的 Android TTS 引擎，对话与角色分别选择音色。音色列表已增加试听和停止；继续完善播放进度、暂停继续和锁屏播放，结合设备反馈覆盖 MultiTTS 默认音色与语音包兼容。

- 共用输入框与设置折叠分组已统一边界和交互。Android 对话已支持离页生成、重新接入任务、列表状态和通知入口；Web 小说生成支持站内跨页继续、全局状态与完成后打开会话。后续继续覆盖不同系统的后台调度与大字号阅读体验；浏览器关闭后的跨进程继续需独立持久任务 owner。

- 平台设置已采用横向标签与分组编辑表单，模型选择列表已增加边界与选中标记；编辑非默认平台只保存该平台，设置默认需要独立操作。Android 用量二三级已拆为独立页面并加入排序与状态筛选；Web 用量已补齐独立平台、模型页及单次请求明细、筛选和分页。继续核对各主题与大字号下的表单、模型长名称和筛选条布局，以及 Web 价格配置与跨端费用语义。

- Android 开篇已接入流式预览、阶段与耗时显示、停止保留和失败重试，DeepSeek 结构化任务已独立配置 JSON 模式与输出预算；开篇已采用整篇事务保存和本地草稿恢复，重启后可继续保存或打开原会话；Android 对话目录已接入编号续章、未完成章节继续、章节命名与小说 TXT 导出；继续完善连续多章生成、平台输出长度控制和生成前的输入草稿恢复。
- Web 开篇已支持提交编号、完整正文暂存和完成回执，保存失败可预览、复制并继续保存，响应丢失后可找回原会话。继续完善暂存本身写入失败时的正文保留。
- 统一百科与工坊为一个世界对象、一个管理入口和一次开局选择。两端已集中世界入口、单次开局选择和生成结果归入，Android Room 20 提供旧资料映射与统一世界编辑；继续完善冲突资料逐项合并、完整交换格式和会话内兼容入口。
- 进一步连接百科知识、工坊玩法与开局选择，提供一致的跨端入口。新开局统一选择世界，旧组合保持兼容；两端对齐初始角色选择，Android 切换百科保留兼容的手动选择。Web 开局已支持本次旁白、剧情选项与规则约束覆盖，并保留失败后的选择；角色失效时先刷新名单再确认创建。
- Android 已增加阅读模式、独立消息搜索、小说目录、段落选择复制和返回最新悬浮入口；平台模型位于输入框下方，模型选择提供横向平台标签和可收起搜索，完整回复保存生成耗时。继续补齐八套主题、小屏大字号、左滑收回、朗读及长篇搜索跳转的设备交互回归。

## P1：核心界面与交互

- 优先统一对话消息的复制、编辑、重试、版本与分支操作，整理会话资料面板及 Web 对应入口。Web 消息操作已同步生成中禁用状态，并补充移动端用途说明；引用支持按会话恢复，发送失败保留，发送期间的新草稿按修订记录保护。Android 消息操作已统一整行布局，补充引用、续写、分支说明和生成中提示；生成期间可引用原文准备下一条输入，引用随会话草稿恢复。两端输入栏引用已采用发言者、两行原文和独立取消入口。Web 消息正文与 Markdown 已补充七套主题对比度检查；Android 已覆盖八套主题的正文、引用、心声与场景文字绘制。
- 首页、创作入口、故事列表、聊天模型入口和公共表单已采用统一的定制 Compose 组件；Web 同步填充表面、按钮形变与弹窗过渡。继续完善对话、角色、世界、模型配置和生成记录的页面布局与信息层级。Web 生成记录已采用自适应卡片与窄屏整行按钮。Android 生成记录卡片已按状态突出主要操作，整卡进入详情，取消收纳到更多菜单；详情支持重试与取消，操作区适配小屏独立滚动。旁白面板已区分自动生成与指定方向，采用纵向操作。旁白方向与配图描述接入按会话本地草稿，写入对话后清空本次输入；配图长输入已限制可见高度。
- 完善小屏、键盘、系统返回、旋转、分屏和字体缩放适配。
- 统一加载、空状态、错误、重试、保存和取消交互。Android 百科条目编辑已加入持续保存错误与重试，正文提交后独立刷新历史版本，刷新失败只重试读取。工坊完整度检查已支持未保存世界、报告过期提示和原位重试。Web 百科封面生成已隔离切换条目后的结果，并支持长描述输入。配图已保存后的刷新失败已提供本地定位入口。
- 改进草稿恢复、深链进入、前进后退和跨页面结果定位。Web 人设补全已保留未应用的参考结果并提供原位重试。Android 人设补全保留手动修改并支持结果读取重试。Android 角色保存已阻止重复提交，新建后的读取失败重试复用原记录。Web 百科库、条目及工坊世界已保留保存期间的新修改，并复用创建结果继续保存；Android 世界补全按字段保留手动修改，结果读取失败支持原位重试。
- 完善平台切换、模型发现、请求停止、超时与限流反馈。Android 已加入按平台和模型配置单价、请求价格快照、首次历史补算、可选历史重算、消息用量及三级消费记录；继续统一 Web 费用语义与跨端配置交换。
  Web 对话和旁白请求已记录实际平台、模型与回复消息，按平台和模型保存价格快照并区分原币；未知价格不再套用固定估价。Web 已能读取平台模型目录中的明确价格并填入草稿。继续完善缓存输入 Token 计费、取消及重试的逐次记录，并统一两端配置交换。

## P2：大型历史

支持单个会话累计几十万至上百万 Token 后的流畅打开、阅读、滚动、搜索、编辑、定位和继续对话。单轮请求按模型预算组合活动上下文。

- 控制消息加载页、可见窗口与内存缓存规模。Android 收藏与故事线摘要已使用专用字段投影、32 条小批读取和后台整理；继续完善大量收藏的分页加载。
- 优化长文本、动态图片高度、连续分页和搜索跳转。Android 搜索摘要已移至后台计算，结果只保留有限片段；继续检查长消息排版与图片加载的滚动稳定性。
- Android 搜索首批结果先显示，总数独立统计；不足一页时直接得到总数，计数失败可单独重试并继续阅读、分页。继续完善大量命中时的结果缓存窗口。
- 完善中文、中英混合、短语与标点搜索。
- 提升多会话、多分支和频繁编辑场景下的增量索引效率。
- 优化索引整理、重新构建与历史重新摘要的进度控制。
- 建立打开、滚动、搜索、定位、内存和数据库体积的性能基线。

## P2：长期记忆

- 完善角色知情范围、秘密、用户纠正和跨分支事实冲突处理。通用记忆已补齐输出结构、嵌套类型校验、文本字段兼容和失败冷却；继续优化自动整理任务的合并与调度。
- 统一摘要、长期事实、自动事件和百科沉淀的来源关联。
- 补齐旧派生数据的整理与失效处理。
- 优化固定设定、近期原文、检索结果与输出空间的预算分配。
- 提供清晰的记忆编辑、来源定位和上下文查看入口。

## P2：导入导出与迁移

- 统一角色、世界、会话、分支、记忆与媒体的版本化交换契约。
- 完善角色卡拆分字段、备选开场白与世界书的导出映射。
- 优化导入预览、冲突处理、重复导入和结果定位。

- 改进 Web 与 Android 之间的资料迁移和本地备份流程。

## P3：可维护性

- 保持页面、状态管理、业务逻辑和存储职责清晰。
- 统一两端会话、消息、分支、错误和交换格式的语义。
- 随功能更新同步维护产品说明、接口说明和操作指南。
- 按完整功能流程安排迭代，同步完成界面、数据、测试与文档。

## 世界入口整合

统一工坊世界与百科世界的管理入口和编辑语义，复用现有世界及百科关联，保留角色、规则、百科条目与会话引用。
