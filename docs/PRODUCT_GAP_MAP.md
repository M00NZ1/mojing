# 墨境持续优化目标

持续优化墨境的角色扮演、长篇对话和世界创作体验，完善 Web 与原生 Android 的功能衔接、界面设计、本地数据管理和大型历史性能。

正式源码位于 `mojing/`。

界面更新覆盖一级、二三级、搜索结果、操作弹层及创建后的编辑流程，逐项范围见 [UI_COVERAGE.md](UI_COVERAGE.md)。

## P1：剧情与记忆一致性

- Android 记忆面板手动“继续整理”已能按当前可见故事线分页扫描旧摘要覆盖空档，并先补齐遗漏原文；扫描进度和分段续跑点独立保存在派生配置中。仍需在设备上验证大型历史首次扫描、跨进程恢复及真实模型整理；自动对话轮仍沿尾部增量整理。
- Android 角色状态锚点已按故事线隔离，基于持久化尝试游标和限量 ID 查询每 15 条新用户消息提取，不再依赖活动上下文窗口的条数。旧无归属快照保留但停止注入；编辑等上下文变更会标记受影响故事线的状态无效。需在设备上验证 22→23 升级、长会话与编辑旧剧情后的再提取。
- Android 消息上下文排除已按故事线、消息/回复组独立存储，并提供排除、恢复入口；阅读采用版本、目录与章节编号保持独立。自动摘要和通用记忆会失效，后续需在设备上验证 Room 迁移、生成中操作、小屏面板及大型历史的增量重整。
- 完善百科推断条目的来源变更提示与长文本整理；Web 与 Android 已支持每批最多 100 条确认。Web 与 Android 沉淀资料已采用游标分页，Android 主条目列表已分页，关系选择器已采用精简字段搜索分页。Android 世界详情打开条目页不再等待时间线和关系图；两个标签分别按 24 条游标分页，关系图明确绘制当前页并可滚动浏览关系，时间线新增失败保留输入，关系删除等待数据库确认并在失败时原位重试。继续在大世界真机上测量翻页、绘图与新增后跨页定位。
- Android 长消息摘要已按轮限制 4 段并持久化经原文与修订校验的续跑位置，记忆面板可手动继续或停止当前故事线的整理，也能补齐旧摘要空档；仍需在设备上验证进程重启、真实模型延迟、取消和大型历史的整理耗时。
- 统一消息操作后记忆、事件、历史窗口与详情面板的更新。Android 事件页已补充状态筛选、操作防重复和原位失败提示；继承事件在来源故事线管理，分支独立事件状态覆盖仍待完善。收藏可定位当前采用版，旧回复版本通过只读弹窗查看原文、不改写采用状态；小屏长文与系统返回仍待设备验收。
- 完善生成任务的暂停、继续、取消、重进恢复与结果管理。Android 人物、普通旁白会定期持久化已收到的部分回复，进程重启后可按原会话和故事线查看、复制、保留或丢弃；已写入的回复用 token 核对，避免重复保留，故事线末尾变化时禁止直接写入。小说章节继续沿草稿保存，开篇可恢复已收到的有限预览并重新生成。仍需设备验证真实停止、进程终止、最后一次检查点后的短尾文本和写入失败。
- Web 普通文本与附件发送已按本次编号去重，并在未收到保存确认时保留可核对、可重试的入口；附件重试需重新选择原文件，服务端逐个比对内容，生成使用已保存消息 ID，避免自动选角丢失本轮正文。继续在真实浏览器验证刷新/断网、附件重选及停止时序。
- Web 对话人物和旁白流在模型异常或生成器关闭时已保存收到的正文，界面标明中断；单轮发言遇错不继续启动后续人物。前端只有收到本轮完成事件才判定成功，连接提前结束会进入失败恢复；服务端响应在断连时显式关闭流。针对已保存用户消息的回复增加活动状态查询和服务端互斥，流关闭且无后续内容才允许同消息重试。待核对回复可在刷新后恢复。继续在真实浏览器验证手动停止、断网、刷新及数据库不可写时的显示与恢复。

- 世界设置已增加按世界隔离的编辑草稿及重进恢复、确认丢弃入口；角色与百科词条编辑已按对象暂存表单并在重进时提供恢复或丢弃，保存与放弃修改会按状态清理草稿。直接进入尚无记录 ID 的新词条编辑路由也可恢复草稿，首次保存后转到正式条目路由。继续在设备上验收进程重建、小屏弹窗及首次保存时的中断窗口。

## P1：当前反馈跟进

- 跟随角色与模型设置时，Key 与接口地址按会话、角色、公共配置整组解析；角色线路测试与实际请求共用主模型和思考模型规则。角色专用线路不借用公共模型，旧会话专用连接沿用公共模型并显示说明；直接选择平台时使用该平台的模型。继续完善旧会话专用配置向平台选择的引导。
- 语音选择支持微软 Azure、系统默认和已安装的 Android TTS 引擎，对话与角色分别选择音色。系统引擎返回重复音色 ID 时已在目录和渲染层去重，避免列表加载或滚动触发 Compose 重复 key 崩溃；音色列表已增加试听和停止。对话朗读期间显示状态和停止入口，系统朗读等待末段完成后才结束该状态。继续在问题设备复测系统音色，并完善播放进度、暂停继续和锁屏播放，结合设备反馈覆盖 MultiTTS 默认音色与语音包兼容。

- 共用输入框与设置折叠分组已统一边界和交互。Android 对话已支持离页生成、重新接入任务、列表状态和通知入口；Web 小说生成支持站内跨页继续、全局状态与完成后打开会话。后续继续覆盖不同系统的后台调度与大字号阅读体验；浏览器关闭后的跨进程继续需独立持久任务 owner。

- 平台设置已采用横向标签与分组编辑表单，模型选择列表已增加边界与选中标记；编辑非默认平台只保存该平台，设置默认需要独立操作。Android 用量二三级已拆为独立页面并加入排序与状态筛选；Web 用量已补齐独立平台、模型页及单次请求明细、筛选和分页。继续核对各主题与大字号下的表单、模型长名称和筛选条布局，以及 Web 价格配置与跨端费用语义。

- Android 开篇已接入流式预览、阶段与耗时显示、停止保留和失败重试，DeepSeek 结构化任务已独立配置 JSON 模式与输出预算；开篇采用整篇事务保存和本地草稿恢复，生成前的输入也可重进恢复并清空；Android 对话目录已接入编号续章、未完成章节继续、章节命名与小说 TXT 导出。继续完善连续多章生成、平台输出长度控制，并在设备上验收输入草稿的离页与进程重建。
- Web 开篇已支持提交编号、完整正文暂存和完成回执，保存失败可预览、复制并继续保存，响应丢失后可找回原会话。暂存写入失败时尝试直接保存会话；仍不可写则向浏览器返回原正文与生成时上下文，刷新后可用同一编号继续保存，无需再调用模型。后续需验证真实模型与浏览器存储限额；响应在到达浏览器前断开时仍可能失去未写入数据库的结果。
- 统一百科与工坊为一个世界对象、一个管理入口和一次开局选择。两端已集中世界入口、单次开局选择和生成结果归入，Android Room 20 提供旧资料映射与统一世界编辑；继续完善冲突资料逐项合并、完整交换格式和会话内兼容入口。
- 进一步连接百科知识、工坊玩法与开局选择，提供一致的跨端入口。新开局统一选择世界，旧组合保持兼容；Android 新建对话与创建小说均已改为百科、未映射旧模板及兼容角色的轻量游标选择器，选定后才读取完整资料；创建小说恢复草稿时保留失效 ID 供用户处理，生成前重新核对。新故事默认设置也只读已选名称，世界模板与百科按需搜索分页。Web 开局已支持本次旁白、剧情选项与规则约束覆盖，并保留失败后的选择；角色失效时先刷新名单再确认创建。世界与角色大量数据的设备耗时及小说生成流程仍待真机实测。
- Android 已增加阅读模式、独立消息搜索、小说目录、段落选择复制和返回最新悬浮入口；平台模型位于输入框下方，模型选择提供横向平台标签和可收起搜索，完整回复保存生成耗时。继续补齐八套主题、小屏大字号、左滑收回、朗读及长篇搜索跳转的设备交互回归。
- Android 搜索在旧消息索引尚未整理完时优先完成当前会话的可续跑分批构建；非主故事线查询先等待可见性区段修复，避免把修复前的旧快照当作完整结果。仍需在百万级历史设备样本上测量首次等待时间与后台重复索引开销。
- Android 重进含分支会话时，在读取对话、摘要和事件前等待派生可见区段修复；失败保持加载错误与重试，避免把旧分支误认为空对话。新建故事线也等新线消息和事件读取成功后才切换当前线，失败留在原线并保留可重试入口。仍需设备验证修复后的上下文连续性、大量故事线的首次等待时间及新建失败体验。
- Android 普通对话刷新只写回发起时所在故事线，旧章节改名刷新晚于切线完成时不再切回旧线；跨线定位和新建、编辑故事线仍使用明确导航入口。需在设备上验证真实数据库延迟下的切换与章节改名交错操作。
- Android 切换故事线的首次滚动位置已按故事线重置，避免从旧线的历史位置进入新线；带指定消息的收藏定位仍优先显示原文。需用长会话在设备上验收切线、焦点与贴底滚动交错时序。

## P1：核心界面与交互

- Android 故事库已按上次阅读的故事线读取当前可见卡片的有限预览，主线卡片和聊天窗口均按消息 ID 确定末尾，主线消息数单独标注；非主线等待派生可见区段修复，失败可重试，生成中仍以任务状态优先。需在设备上验证旧分支、无消息分支、切线后立即返回、长历史查询耗时与小屏布局。
- 优先统一对话消息的复制、编辑、重试、版本与分支操作，整理会话资料面板及 Web 对应入口。Web 消息操作已同步生成中禁用状态，并补充移动端用途说明；引用支持按会话恢复，发送失败保留，发送期间的新草稿按修订记录保护。Android 消息操作已统一整行布局，补充引用、续写、分支说明和生成中提示；生成期间可引用原文准备下一条输入，引用随会话草稿恢复。两端输入栏引用已采用发言者、两行原文和独立取消入口。Web 消息正文与 Markdown 已补充七套主题对比度检查；Android 已覆盖八套主题的正文、引用、心声与场景文字绘制。
- 首页、创作入口、故事列表、聊天模型入口和公共表单已采用统一的定制 Compose 组件；Web 对话首页已提供最近 3 段故事的直接续聊、最近消息预览和窄屏完整列表入口，预览所属故事线与续聊路由已对齐。继续完善对话、角色、世界、模型配置和生成记录的页面布局与信息层级，并用正式本机数据及各主题验收新首页和旧分支深链。Web 生成记录已采用自适应卡片与窄屏整行按钮。Android 生成记录卡片已按状态突出主要操作，整卡进入详情，取消收纳到更多菜单；详情支持重试与取消，操作区适配小屏独立滚动。旁白面板已区分自动生成与指定方向，采用纵向操作。旁白方向与配图描述接入按会话本地草稿，写入对话后清空本次输入；配图长输入已限制可见高度。
- 完善小屏、键盘、系统返回、旋转、分屏和字体缩放适配。
- 统一加载、空状态、错误、重试、保存和取消交互。Android 故事库已在后续读取失败时保留上次成功列表，并提供顶部重试；首次读取失败仍显示独立错误页。Android 故事线创建与切换在会话标题下显示进行中状态，完成后清除，并禁止菜单重复触发；百科条目编辑已加入持续保存错误与重试，正文提交后独立刷新历史版本，刷新失败只重试读取。工坊完整度检查已支持未保存世界、报告过期提示和原位重试。Web 百科封面生成已隔离切换条目后的结果，并支持长描述输入。配图已保存后的刷新失败已提供本地定位入口。
- 改进草稿恢复、深链进入、前进后退和跨页面结果定位。Android 新建对话表单已保存页面恢复状态，重建后重新读取世界资料；角色选择改为轻量 ID 校验与每页 40 条的数据库搜索，不再载入全部完整角色卡，跨页保留选择；原选世界消失时禁止按空世界误建。有修改时关闭会确认放弃；去创建角色暂存本次设定与创建编号，返回故事库可继续并刷新兼容角色，指定其他世界替换草稿需确认。同一创建编号重试复用原会话；事务成功但打开失败时提示从故事库进入，不再误报创建失败。仍需设备验收跨页返回、旋转、系统回收、24→25 升级及创建中断时序。Web 人设补全已保留未应用的参考结果并提供原位重试。Android 人设补全保留手动修改并支持结果读取重试。Android 角色保存已阻止重复提交，新建后的读取失败重试复用原记录。Web 百科库、条目及工坊世界已保留保存期间的新修改，并复用创建结果继续保存；Android 世界补全按字段保留手动修改，结果读取失败支持原位重试。
- 完善平台切换、模型发现、请求停止、超时与限流反馈。Android 已加入按平台和模型配置单价、请求价格快照、首次历史补算、可选历史重算、消息用量及三级消费记录；继续统一 Web 费用语义与跨端配置交换。
  Web 对话和旁白请求已记录实际平台、模型与回复消息，按平台和模型保存价格快照并区分原币；未知价格不再套用固定估价。Web 已能读取平台模型目录中的明确价格并填入草稿。继续完善缓存输入 Token 计费、取消及重试的逐次记录，并统一两端配置交换。

## P2：大型历史

支持单个会话累计几十万至上百万 Token 后的流畅打开、阅读、滚动、搜索、编辑、定位和继续对话。单轮请求按模型预算组合活动上下文。
