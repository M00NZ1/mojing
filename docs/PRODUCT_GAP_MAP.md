# MoJing 公开路线图

本路线图只记录仍有用户价值的未闭环方向，不保留过时施工清单或逐日完成记录。优先级可随当前证据调整。

## P1：核心流程与真实设备验收

- Web/Android 多平台配置与聊天选择已实现；Web 模拟 API 浏览器回归已通过，仍需真实本机服务/供应商联调；Android 待真机验证小屏、键盘、获取取消和生成中切换；
- Web 角色导入入口、创建时间排序、结果定位、原子保存与 TXT/DOCX 往返已修复；隔离 SQLite/HTTP 与浏览器模拟验证通过，待真实用户文件回归；
- Android 新示例目录、统一角色排序与生成记录改版已实现，待设备验证旧目录迁移/回滚、暂停后重进、失败续跑和结果跳转；Web 新示例目录及配套开局已实现，旧示例无损收起/恢复通过隔离验证，待真实旧库升级验收；
- Web 生成结果刷新找回、记录详情、幂等保存、摘要分页与成功状态已完成，隔离数据库/HTTP 和模拟 API 浏览器验证通过；旧记录缺失的原始结果不能追溯补回；
- Web 世界生成已支持异步请求取消、离页保护和浏览器草稿恢复，隔离回归通过；仍需真实供应商线路验证停止时延。新任务已加入检查点暂停/续跑和本机执行所有者退出后的中断恢复，Windows 隔离进程、SQLite/HTTP 与浏览器模拟验证通过；仍需真实供应商暂停时延和完整本机服务联调，旧记录缺失的输入/进度不能追溯补回。Android 对应能力待真机验证；

- 在代表性 Android 真机上完成 IME、系统/手势返回、旋转/分屏、权限和文件选择器矩阵；
- 在真实浏览器完成窄屏、深链、前进/后退、草稿恢复、停止/重试和附件失败矩阵；
- 验证 Android 新标识下从早期构建导出、在 MoJing 导入的数据往返；
- 用真实供应商线路验证停止、超时、限流、无效凭据和部分媒体失败。

## P2：大型历史与长期连续性

- Web 搜索已完成本机增量索引、字面匹配和结果游标翻页；180 万 Token 隔离 SQLite 与 6,000 消息模拟 API 浏览器验证通过。仍需真实浏览器/Backend 联调及代表性 Android 设备验证累计历史的打开、分页、滚动、搜索、跳转、编辑和继续生成；
- 持续记录 Web/Android 的延迟、内存、数据库大小和索引重建指标；Web 当前已有桌面 SQLite 查询/批次时间及体积基线，极长单条消息、多会话/多分支、高频写入与动态媒体高度仍需性能验收；
- 验证编辑、删除、分支、回复版本变化后的摘要/记忆/搜索索引失效与重建；
- 用长剧情样本评估角色知情边界、秘密、用户纠正和跨分支事实冲突。

## P2：跨端交换

- 固化角色、世界、会话、分支、记忆和媒体的版本化交换契约；
- 增加旧版本、重复导入、损坏包、大文件和取消恢复测试；
- 提供导入前预览、冲突说明和导入后校验结果。
- Web 世界包已实现完整校验后原子导入，失败保留旧资料；隔离数据库与模拟 API 浏览器回归通过，仍需真实本机服务及跨端交换验收。

## P3：体验与可维护性

- 持续统一 Web/Android 的空状态、错误、重试、取消和返回语义；
- 把诊断、Token 分配和来源说明保留在高级入口，避免干扰日常创作；
- 定期复核第三方供应商协议、模型列表和错误提示；
- 保持公开文档短而有效，不再累积个人路径、旧审计快照和施工流水账。

## 完成标准

一个条目只有在实现、自动验证、相关真实运行、文档和数据安全检查均完成后才算闭环。构建或静态检查不能替代浏览器、模拟器、真机或大型数据证据。
