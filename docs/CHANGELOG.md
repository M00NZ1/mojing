# 更新日志

## 开发中 · 2026-09-26

### Android

- 修复部分系统朗读引擎返回重复音色时，音色列表加载或滚动后直接退出应用的问题。
- 会话事件改为最近 24 条起步的游标分页，支持继续加载和失败重试，长对话不再反复读取全部事件。
- 事件面板按最新事件在前显示，继续加载的较早事件接在末尾，浏览顺序与分页方向一致。
- 翻阅较早事件后，同一故事线的消息刷新保留已展开范围；新建或切换故事线时从最近一页重新开始。
- 新建故事线在消息与事件读取成功后才切换当前会话；读取失败时保留原故事线，并按能否读取故事线列表给出可执行的重试提示。
- 故事线创建或切换等待期间在会话标题下显示进度，完成或失败后恢复原信息，并阻止菜单重复触发。
- 章节改名等旧故事线的读取完成后，不再把已经切到新故事线的对话界面拉回旧线。
- 从较早消息切换故事线时，新线定位到最近消息；从收藏等入口定位指定消息时仍显示目标原文。
- 对话生成中断后可在重进会话时查看、复制或保留已收到的回复，并核对消息位置以避免重复写入。
- 长消息搜索的摘要与原文高亮改在后台处理，减少阅读时的主线程工作。
- 旧消息搜索索引未整理完时显示等待状态；搜索当前会话时优先整理该会话，再显示完整命中和总数。
- 非主故事线搜索会先确认可见消息索引已修复，避免恢复期间显示漏掉或串入其他故事线的结果；修复失败可重试。
- 重进已有故事线时先确认可见消息已修复，避免把暂时读不到的历史当作新对话继续生成。

## 1.1.0 · 2026-09-23

### Android

- 对话可在离开页面后继续生成，并在会话列表查看状态或停止；优化长消息阅读宽度、键盘打开时的操作入口、文字选择与消息操作。
- 新建对话的世界和角色改为可搜索选择；角色、世界、百科、工坊、故事、记忆、搜索、模型、用量和设置的深层页面统一整理布局、表单层级、选中状态及保存反馈。
- 支持微软 Azure 语音和设备已安装的 TTS 引擎，分别为默认朗读与角色选择引擎和音色，并在保存前试听；优化系统朗读失败及接口错误提示。
- 在设置中查看当前版本、检查 GitHub 新版本并打开适配设备的安装包下载；小说目录支持中文章号识别、续章命名与 TXT 导出。
- 修复角色未绑定百科时无法开聊、非默认平台编辑影响默认线路、回复版本跨页选择、收藏定位和多个编辑流程中的草稿或失败状态丢失。
- 优化可见消息文本与收藏摘要处理，减少阅读和搜索过程中的主线程工作。

### Web 与本机数据

- 世界库、角色库、平台设置及聊天搜索改为更清晰的完整页面与阅读流程；小说生成可在站内切换页面后继续查看状态。
- 模型费用支持按平台和模型配置人民币或美元单价、读取明确的目录报价、补算未计价历史及选择是否重算旧费用；回复下方显示耗时、Token 和费用，用量按平台、模型、请求逐级查看。
- 修复角色与百科编辑保存失败后的草稿保留、离开对话时的消息编辑保护，以及搜索定位失败后的原位重试。

安装包提供通用、ARM64 和 ARMv7 三种版本。首次安装请选择通用版；已有安装可使用相同签名的新版 APK 升级。
