# 更新日志

## 1.2.1 · 2026-09-30

### Android

- 朗读音色选择更清楚地区分系统默认与指定引擎；切换引擎时显示加载状态，避免旧引擎音色短暂混入新列表。重复音色标识采用稳定映射，并在朗读时显示本次请求的设置来源。
- 对话首屏按需读取世界资料、记忆、摘要、纠正、书签和事件；长正文排版与语音预处理移到后台，改善大型会话的进入和阅读体验。
- 修复历史消息刷新覆盖新窗口、返回同内容窗口后 Token 估算缺失、分支入口初次进入不显示、平台配置读取失败无法重试，以及旧模型列表重复项可能导致的页面异常。
- 角色库和世界资料导出支持分批处理与中断恢复；搜索结果摘要限制读取范围，点开时仍能查看完整原文。

### Web

- 模型报价读取失败时保留错误与重试入口，避免把旧报价误当作未配置并覆盖。

### 构建

- CI 临时 APK 仅保留 1 天，并停止写入 Gradle Actions 缓存，以控制 GitHub 存储占用；正式安装包仍通过 Releases 提供。

## 1.2.0 · 2026-09-29

### Android

- 修复部分系统朗读引擎返回重复音色后，进入音色列表数秒便直接退出应用的问题；音色目录改在后台读取，对话中可查看和停止当前朗读。
- 会话事件从最近 24 条开始按游标翻页；删除事件或刷新消息后保留已展开范围，较早事件继续接在列表末尾。
- 小说、角色、世界与新建故事选择器按需分页读取，搜索覆盖完整资料库；长列表和大段预览不再依赖一次性加载全部内容。
- 消息搜索支持按发言角色查找、查看命中上下文并跳转到原文；旧消息索引未完成时显示进度，优先整理当前会话，非主故事线先核对可见范围。
- 切换或新建故事线会等待消息与事件加载成功；失败保留原故事线并提供重试，旧加载结果不会把界面拉回已离开的故事线。
- 对话流提前断开或达到输出上限时保留已收到的回复；连续 5 分钟无正文才结束等待，持续正常输出不受总时限截断。重进会话可查看和处理未完成回复。
- 小说开篇生成支持中断预览恢复和长篇持续输出；停止并离开会等待有限预览与创作设定写入，暂存失败时留在页面供复制或重试。续章输入、待保存正文与目录跳转的失败状态也可恢复。
- 聊天和百科导入分批写入并保持失败回滚；百科导入显示进度且可取消，世界资料与模板导出按需流式处理。
- 角色、百科编辑草稿和新建会话设定可在离开或进程重建后恢复；删除世界关系须确认，失败时保留原内容。
- 搜索高亮、朗读目录和大批量数据处理移出界面线程，减少长会话阅读与资料浏览时的卡顿。

## 1.1.0 · 2026-09-23

### Android

- 对话可在离开页面后继续生成，并在会话列表查看状态或停止；优化长消息阅读宽度、键盘打开时的操作入口、文字选择与消息操作。
- 新建对话的世界和角色改为可搜索选择；角色、世界、百科、工坊、故事、记忆、搜索、模型、用量和设置的深层页面统一整理布局、表单层级、选中状态及保存反馈。
- 支持微软 Azure 语音和设备已安装的 TTS 引擎，分别为默认朗读与角色选择引擎和音色，并在保存前试听；优化系统朗读失败及接口错误提示。
- 在设置中查看当前版本、检查 GitHub 新版本并打开适配设备的安装包下载；小说目录支持中文章号识别、续章命名与 TXT 导出。
- 修复角色未绑定百科时无法开聊、非默认平台编辑影响默认线路、回复版本跨页选择、收藏定位和多个编辑流程中的草稿或失败状态丢失。
- 优化可见消息文本与收藏摘要处理，减少阅读和搜索过程中的主线程工作。

### Web 与本机数据

- 世界库、角色库、平台设置及聊天搜索改为更清晰的完整页面与阅读流程；小说生成可在站内切换页面后继续查看状态。
- 模型费用支持按平台和模型配置人民币或美元单价、读取明确的目录报价、补算未计价历史及选择是否重算旧费用；回复下方显示耗时、Token 和费用，用量按平台、模型、请求逐级查看。
- 修复角色与百科编辑保存失败后的草稿保留、离开对话时的消息编辑保护，以及搜索定位失败后的原位重试。

安装包提供通用、ARM64 和 ARMv7 三种版本。首次安装请选择通用版；已有安装可使用相同签名的新版 APK 升级。
