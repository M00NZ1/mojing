# 更新日志

## 1.1.0 · 2026-09-23

### Android

- 对话可在离开页面后继续生成，并在会话列表查看状态或停止；优化长消息阅读宽度、键盘打开时的操作入口、文字选择与消息操作。
- 新建对话的世界和角色改为可搜索选择；角色、世界、百科、工坊、故事、记忆、搜索、模型、用量和设置的深层页面统一整理布局、表单层级、选中状态及保存反馈。
- 支持微软 Azure 语音和设备已安装的 TTS 引擎，分别为默认朗读与角色选择引擎和音色，并在保存前试听；优化系统朗读失败及接口错误提示。
- 在设置中查看当前版本、检查 GitHub 新版本并打开适配设备的安装包下载；小说目录支持中文章号识别、续章命名与 TXT 导出。
- 修复角色未绑定百科时无法开聊、非默认平台编辑影响默认线路、回复版本跨页选择、收藏定位和多个编辑流程中的草稿或失败状态丢失。
- 优化可见消息文本与收藏摘要处理，减少阅读和搜索过程中的主线程工作。

### Web 与本机数据

- 世界库、角色库、平台设置及聊天搜索改为更清晰的完整页面与阅读流程；小说生成可在站内切换页面后继续查看状态。
- 模型费用支持按平台和模型配置人民币或美元单价、读取明确的目录报价、补算未计价历史及选择是否重算旧费用；回复下方显示耗时、Token 和费用，用量按平台、模型、请求逐级查看。
- 修复角色与百科编辑保存失败后的草稿保留、离开对话时的消息编辑保护，以及搜索定位失败后的原位重试。

安装包提供通用、ARM64 和 ARMv7 三种版本。首次安装请选择通用版；已有安装可使用相同签名的新版 APK 升级。
