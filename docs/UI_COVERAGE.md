# 墨境界面更新范围

覆盖 Android 与 Web 的完整使用流程，包含入口、详情、新建、编辑、搜索、弹窗、抽屉和操作反馈。修改共享组件只计入组件覆盖，不代表调用页面已完成视觉验收。

## Android 本轮视觉体系

故事库、设置分类首页及内容页采用新的页面层级。共用表单标签固定在输入区上方，输入面使用浅层表面与细边框，按钮统一紧凑圆角；展示标题使用衬线字形，正文沿用系统阅读字体。创作入口减少整块强调色，默认深浅主题调整为中性底色。以上是代码覆盖范围，逐页显示仍需运行检查；角色列表与编辑页、聊天输入区及工具面板已接入本轮层级；世界及其他深层页面继续调整。

## 每条流程的完成条件

- 页面层级、排版、间距、语义色与主要操作统一；长名称和长正文不挤压操作区。
- 入口到详情、创建后编辑、搜索后定位及返回路径完整。
- 加载、空、失败、重试、保存中、未保存退出与禁用状态明确。
- 检查深浅主题、小屏、字体放大、键盘和长列表。
- 用对应页面的运行截图核对最终显示；源码修改、编译和截图检查分别记录。
