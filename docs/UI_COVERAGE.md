## 每条流程的完成条件

- 页面层级、排版、间距、语义色与主要操作统一；长名称和长正文不挤压操作区。
- 入口到详情、创建后编辑、搜索后定位及返回路径完整。
- 加载、空、失败、重试、保存中、未保存退出与禁用状态明确。
- 检查深浅主题、小屏、字体放大、键盘和长列表。
- 用对应页面的运行截图核对最终显示；源码修改、编译和截图检查分别记录。
