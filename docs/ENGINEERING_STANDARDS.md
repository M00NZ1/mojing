# 墨境工程标准

生效日期：2026-09-28。适用于 `mojing/` 的 Android、Web 与本机后端；当前开发优先保障 Android。用户当前任务、`AGENTS.md` 的数据保护与发布授权规则优先于本文。本文规定新功能和改动所遵循的默认值；现有实现若不同，按文末登记逐批迁移，不能仅为统一数字而改写用户数据或核心流程。

## 列表、分页与内存

| 场景 | 默认单页 | 补充约束 |
| --- | ---: | --- |
| 模型等短选择器、搜索建议 | 10 | 只保留当前选择需要的字段 |
| 图片、长正文卡片、事件 | 24 | 允许按实测在 20–24 内选择 |
| 普通文本列表、收藏、搜索命中、目录、用量记录 | 40 | 仅投影展示字段，正文按需读取 |
| 自动摘要等长文本派生资料 | 16 | 展开详情按需读取 |
| 聊天消息 | 首屏 80、后续 40 | 内存窗口最多 200 条消息实体 |
| 后台索引、导出等无 UI 批处理 | 128–256 | 分批处理，不等同于 UI 页大小 |

页大小是默认值，不是所有页面统一 10 条。实现时在对应模块定义有名称的常量；与默认值不同，应记录载荷、设备或使用场景的理由，并做相应验证。服务端上限、批量确认上限和 UI 页大小分别命名，不复用一个数字表达不同约束。

- 面向用户的历史和列表必须有界读取；深分页使用稳定的游标，包含排序字段和唯一 ID。默认读取 `pageSize + 1` 判断是否还有下一页；已有可靠的 `nextCursor` 或独立总数时可复用该结果。只读满一页而未确认后续记录时，应将“可能还有”与“确定还有”区分，不对大型历史使用 Offset 深分页。
- 首屏不为总数阻塞。只有搜索与用量默认提供精确总数，并在后台独立统计；其他列表在未知总数时显示“已加载 N+”，不把已加载条数冒充总数。
- 本地轻量列表接近底部时自动加载。长正文、事件、模型调用、导入和昂贵统计使用明确按钮。保留首屏、加载、空结果、失败、重试、结束及筛选切换状态；后续页失败时保留已经显示的内容。用户触发的创建、保存、导入操作在持久化确认前保持进行中状态；结果不明时保留输入并提供核对或重试入口。
- 聊天窗口上限为 200 条。普通搜索结果默认最多缓存 3 页，图片或长正文卡片默认最多缓存 5 页；返回更早内容时按游标再读。用户主动逐页展开的资料面板可暂留已加载页，但上线大型数据前必须测量并确定上限。
- 切换会话、故事线、筛选或关键词时取消旧任务，用请求修订号阻止旧结果覆盖新状态。新增、删除、编辑后刷新受影响的有界窗口，保留用户的位置与已加载内容。

## 请求、重试与文件

| 操作 | 默认处理 |
| --- | --- |
| 模型流式生成 | 无固定总时限；分别控制连接、读取和空闲等待；停止或断线时保留最新收到的可显示正文 |
| 普通元数据 HTTP | 连接 15–30 秒，读取 30–60 秒，按服务特性在范围内选值 |
| 系统能力查询（如 TTS 音色） | 目标 8–10 秒；失败或超时给出可重试状态 |
| 用户主动试听、预览 | 目标 30 秒，提供停止入口 |
| 本地数据库读取 | 不设人为总时限；通过后台执行、分页、索引与取消控制延迟 |

- 本地读取失败保留旧数据并提供原位重试，不循环自动重试。网络只读请求至多自动重试一次，且只针对暂时性网络故障；认证、限流和参数错误交给用户处理。
- 创建、发送、导入和付费请求只有具备幂等请求编号和结果核对路径后才可重放。数据库写入结果不明时先核对已提交状态，不能盲目重复写。
- 新导入流程优先采用流式解析、进度、取消、预检和事务提交。图片 32 MiB、角色/百科结构化文件 128 MiB、聊天/备份 512 MiB 是**软警告参考值**，超过时告知预计时间与空间；任何硬限制必须依据格式、解析器、内存或存储安全另行说明。覆盖导入不得先清空正式数据。

## 日志、性能与验证

- Android 会话日志单文件目标上限 20 MiB，保留当前与上一次轮换文件，合计约 40 MiB。诊断可记录崩溃栈、请求 ID、引擎和模型标识；不得记录完整密钥、认证头、签名密码或私密正文。
- 性能验收先固定一台中端 Android 真机和一套桌面浏览器环境，记录数据规模、版本、冷/热启动、首批可交互时间、翻页反馈和滚动表现。形成基线后再设硬性毫秒或帧率门槛；百万 Token 历史必须保持窗口读取。
- 新分页的数据和状态层至少覆盖 0、1、`pageSize - 1`、`pageSize`、`pageSize + 1` 条，同时间不同 ID，翻页时数据变化，失败重试与旧请求晚到。迁移要回放旧 schema，确认原始数据保留、遍历无重复遗漏。UI 测试按风险选取小屏、长文本、滚动与返回场景。
- 每个提交只包含一个逻辑变更，暂存当前任务文件后复核 diff。P0/P1 修复要有根因证据、定向验证和可安装构建，或明确说明未构建原因。APK 发布核对包名、版本、ABI、签名证书与 SHA-256；推送后核对远端 SHA 和 CI。用户反馈、单测、构建、模拟器和真机结果分别报告。

## 落地与例外

新代码和改动过的流程从本标准选默认值；确有产品或性能原因时，在该模块附近说明所选数值与依据。既有实现不因本文生效而自动变更。按用户影响和真实证据逐批调整，改动一项就验证一项，并更新此处的例外登记。

每批涉及列表、请求或导入时，在提交前核对四件事：选用的默认值或例外理由；有界查询及旧请求隔离；加载、错误、重试和取消路径；对应的数据/状态测试与真实运行证据边界。跨端功能先统一数据和错误语义，再分别确定适合各端的展示数量。

截至 2026-09-28 的源码核对结果：

| 位置 | 当前值或行为 | 后续处理 |
| --- | --- | --- |
| Android 聊天、收藏、摘要、事件 | 聊天 80/40/200；收藏 40；摘要 16；事件 24 | 与默认值一致；事件连续手动加载后的内存规模仍待大库实测 |
| Android 独立消息搜索 | 每页 40 条，最多缓存连续 120 条命中 | 与普通列表及三页缓存默认值一致；总数另行统计 |
| Android 故事库 | 每页 40 条，只保留当前页；显式上一页/下一页 | 置顶、编辑和删除会改变排序，保留整库或自动累积会放大逐卡片元数据读取；用 `(pinnedAt, updatedAt, id)` 游标翻页，改序后回首批重建游标。设备滚动与大库首屏仍待实测 |
| Android 新建对话的角色选择 | 每页 40 条，只保留当前页；显式上一页/下一页 | 多选角色时减少跨页往返；只读取名称与排序字段，数据库搜索覆盖全部兼容角色，跨页保留已选 ID。大角色库设备耗时仍待实测 |
| Android 新建对话的世界选择 | 每页 40 条，只保留当前页；显式上一页/下一页 | 世界百科与未映射旧模板按原分组顺序展示，候选只读名称、数量和排序字段；选中后再读完整世界。大世界库设备耗时仍待实测 |
| Android 创建小说的世界和角色选择 | 每页 40 条，只保留当前页；显式上一页/下一页 | 复用新建对话的轻量游标选择器与数据库搜索；草稿只校验已选 ID，生成前按 ID 读取完整设定和角色。大资料库弹层及真机生成待实测 |
| Android 角色主页 | 每页 40 条，只保留当前页；显式上一页/下一页 | 推荐、最近添加和名称排序分别使用排序字段与 ID 游标；卡片只读名称、图片路径、当前百科名称和前 72 字人设，详情再读取完整角色。百科筛选独立搜索并每页显示 40 个轻量选项；大角色库排序耗时仍待设备测量 |
| Android 角色导入/导出的百科名称映射 | 当前一次读取全部 ID/名称 | 需要按原规则完成跨设备名称匹配；只读取轻量名称，不读取世界正文。世界库达到大型样本时改为 256 条一批扫描并测量峰值内存 |
| Android 世界主页 | 每页 24 张封面卡片，只保留当前页；显式上一页/下一页 | 名称搜索覆盖全库，卡片仅读取展示字段和截断简介，使用置顶时间、更新时间、ID 游标；封面与资料改动后重读首批。大世界库设备耗时与小屏翻页待实测 |
| Android 设定工坊模板页 | 每页 24 张封面卡片，只保留当前页；显式上一页/下一页 | 名称、摘要和分类搜索覆盖全库；卡片只读展示字段与前 96 字摘要，完整模板在编辑、生成和导出时读取。大模板库设备耗时待实测 |
| Android 会话内旧搜索面板 | 每页最多 100 条 | 独立于搜索页的旧入口；后续按实际使用和设备数据决定是否统一，不因标准生效直接改动 |
| Android 小说目录 | 每页 40 条；读满一页时提示可能有后续页 | 沿用现有有界游标查询；末尾恰好满页时可能再读一次空页 |
| Android 导入读取器 | 结构化文本 16 MiB、角色 32 MiB、世界资料 64 MiB 硬上限 | 保留安全边界；要支持大文件时先改流式解析并验证，再评估软警告 |
| Android 会话日志 | 单文件 20 MiB，保留上一文件 | 与默认值一致 |
| Web 模型选择器 | 每页 10 条 | 与默认值一致 |

需要长期保留不同数值时，将理由、影响范围和验证证据写入对应模块或产品文档；标准不要求跨端使用相同 UI 数字，但数据语义、游标稳定性、错误与恢复规则必须一致。
